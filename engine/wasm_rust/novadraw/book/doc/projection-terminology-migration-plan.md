# “投影”术语拆分与迁移方案

类型：`book-maintenance-plan`

状态：`completed`

适用范围：

- `book/user/`：《Novadraw 应用开发与扩展指南》
- `book/internals/`：《深入理解 Novadraw》
- `book/contributor/`：《Novadraw 贡献者指南》
- `book/README.md`、`book/WRITING_PROFILE.md` 和三本书的维护规则

## 1. 问题

当前书稿使用“投影”表达至少两种不同机制。

### 1.1 模型到视图

业务模型经过 Viewer、Part 和 Runtime，形成可重建的 Part/Figure 视图。这里的
`projection` 表示从权威模型事实派生当前视图，不表示几何投影。

典型表达：

- 模型投影；
- Viewer 投影；
- containment projection；
- connection projection；
- 投影事务；
- 投影 revision；
- 同步投影。

### 1.2 几何到目标坐标域

点、矩形或视觉范围经过祖先变换进入父内容域或逻辑表面域，并在需要时取保守 AABB。
这里多数操作是坐标变换和包围盒计算，不是严格数学意义上的投影。

典型表达：

- 几何投影；
- damage 投影；
- 表面投影；
- projected bounds；
- 重新投影。

### 1.3 当前后果

同一中文词同时表达“派生视图”和“变换几何”，会产生以下问题：

- 读者无法仅凭术语判断所属状态平面；
- “投影”容易被理解为三维到二维或不可逆降维；
- “投影 revision”看不出它实际属于 Viewer；
- “重新投影”无法区分同步模型变化和重新计算坐标；
- 三本书难以保持 BP-03“一个概念一个首选名称”。

## 2. 术语裁决

正文不再把“投影”作为跨领域通用词。根据机制拆成“视图派生”和“坐标变换”两组。

### 2.1 模型到视图

| 当前表达 | 首选表达 | 使用条件 |
|---|---|---|
| 模型投影 | 模型到视图的派生；简称“视图派生” | 解释模型与视图关系 |
| 投影结果 | 派生视图；稳定视图 | 指 Part/Figure 结果 |
| Viewer 投影 | Viewer 视图派生 | 指总体机制 |
| 刷新投影 | 同步视图 | 已有 Viewer 消费模型变化 |
| 初始投影 | 构建初始视图 | 从快照首次创建 |
| 重建投影 | 重建视图 | revision 断裂或 Viewer 重建 |
| 投影事务 | 视图同步事务 | plan/validate/commit/publish |
| 投影 revision | Viewer revision；视图版本 | 优先使用代码中的准确身份 |
| 投影控制器 | 视图控制器 | 指 EditPart 职责 |
| containment projection | containment 视图构建 | 首次出现保留英文便于检索 |
| connection projection | 连接视图构建 | 指 ConnectionPart/Figure 构建 |
| 投影 registry | 视图映射表；Part registry | 按实际数据结构选择 |

本组核心定义：

> 视图派生是 Viewer 根据单一模型 revision 构建或同步 Part/Figure 视图的确定性过程。
> 模型是业务事实，派生视图可以销毁和重建。

普通叙述优先使用动词：

- 构建视图；
- 同步视图；
- 重建视图；
- 从模型派生 Figure；
- 把模型身份映射为 Part 身份。

不要为了替换名词而反复写“视图派生”。动作明确时直接写动作。

### 2.2 几何到目标坐标域

| 当前表达 | 首选表达 | 使用条件 |
|---|---|---|
| 坐标投影 | 坐标变换 | 点或向量跨坐标域 |
| 几何投影 | 几何变换 | 形状跨坐标域 |
| 投影到表面 | 变换到逻辑表面域 | 必须写明目标域 |
| 表面投影 | 表面几何；表面范围 | 指结果 |
| projected bounds | 变换后包围盒；表面包围盒 | 根据目标域选择 |
| projected visual bounds | 表面视觉包围盒 | damage 语境 |
| damage 投影 | 把视觉范围变换到表面域 | 避免名词堆叠 |
| 重新投影 | 按当前变换重新计算 | 说明重新计算的对象 |
| 逆投影 | 逆变换到节点本地域 | 仅仿射可逆场景 |
| 投影链 | 祖先变换链 | 绘制、命中、damage 共用 |

本组核心定义：

> 坐标变换把几何从一个明确坐标域映射到另一个坐标域。矩形经过旋转或倾斜后，需要对
> 变换后的角点计算保守轴对齐包围盒。

只有下列情况可以保留“投影”：

- 真实的 projective transform、透视变换或降维；
- 引用外部规范、代码标识符或原文术语；
- 讨论旧术语本身；
- `projection` 是必须保留的源码名称，且正文已解释其书中首选中文名。

## 3. 非目标

本次只调整书籍表达，不修改：

- Rust 类型、函数、模块和测试名称；
- 已接受 ADR 和规范性设计的代码标识符；
- 历史审计证据、旧提交说明和归档文档；
- ModelId、EditPartId、FigureId 的身份模型；
- Viewer 的同步和故障锁定协议；
- 坐标、damage 或 AABB 的实际算法。

若规范性文档本身也需要术语迁移，应另建 ADR/设计文档任务，不能由书稿计划反向修改
唯一事实源。

## 6. 禁止的迁移方式

- 禁止对“投影”执行无上下文全局替换；
- 禁止把所有“投影”统一替换为“映射”；
- 禁止修改 Rust 标识符来配合书稿用词；
- 禁止把 `projection.rs` 等真实路径写成不存在的新路径；
- 禁止把视图派生描述为模型副本；
- 禁止把仿射坐标变换描述为不可逆降维；
- 禁止在三本书中分别发明不同译法。

每个命中必须先分类为：

```text
模型到视图
坐标域变换
真实 projective 语义
代码标识符或外部原文
历史文本
无法判定
```

“无法判定”必须回到上下文和规范事实确认，不能猜测替换。
