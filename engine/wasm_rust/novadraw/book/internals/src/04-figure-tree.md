# 4. Figure 树与组合语义

Figure 树是组合关系、叠放顺序、绘制顺序、命中顺序和坐标传播共同依赖的结构事实。

本章解释：

- Figure 行为、FigureNode 状态和 FigureTree 拓扑为何分离；
- 父子双向一致、无环、单一父级和深度限制；
- 容器接纳规则如何约束结构；
- 绘制顺序与逆序命中的对应关系；
- 生命周期清理为何不能退化为删除一个子节点；
- 图层和复合图形为何仍服从同一棵树。

核心结论：

> 共享同一棵树不是实现便利，而是绘制、交互和几何结果一致的前提。

本章应通过添加、换父、删除和销毁四种操作说明：结构发布之前需要检查什么，提交后又
必须清理哪些跨模块关系。
