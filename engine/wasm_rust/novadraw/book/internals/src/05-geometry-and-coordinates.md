# 5. 几何、坐标域与变换

绘制、命中、布局、连接和重绘只有使用同一套几何事实，才能在嵌套、滚动和缩放后仍然
对齐。

本章解释：

- bounds、local border box、client area、visual bounds 与 projected bounds；
- 父内容域、节点本地域、子内容域和逻辑表面域；
- 每条父子边携带的平移和附加变换；
- 仿射矩阵组合为何不可交换；
- 视口与缩放如何进入普通祖先变换链；
- 不可逆变换、裁剪和保守轴对齐包围盒。

核心结论：

> 坐标不是一对裸数字；每个点和矩形都必须属于明确的坐标域。

本章应以一个包含边框、内边距、视口和缩放的嵌套场景，分别推导绘制下降、命中上升和
damage 投影，并证明三者使用同一变换链。
