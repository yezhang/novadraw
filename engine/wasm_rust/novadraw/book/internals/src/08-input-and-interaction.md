# 8. 命中、输入与交互状态

平台提供的是离散事件，用户感知到的却是悬停、拖拽、焦点和文本编辑等跨事件会话。

本章解释：

- 平台事件归一化与逻辑表面坐标；
- 命中测试为何与绘制顺序互为镜像；
- 容器命中、自身命中和事件目标；
- hover、capture、focus 与 gesture state；
- 回调效果队列如何避免重入修改；
- Core 处理结果与 Editor 工具之间的仲裁；
- 键盘输入、文本输入和 IME 状态机。

核心结论：

> 单次事件没有完整交互语义；交互必须由持有明确身份和取消路径的状态机解释。

本章应按 pointer down、move、up/cancel 的时间顺序展开，并覆盖指针离开、对象销毁、
窗口失焦和迟到文本事件。
