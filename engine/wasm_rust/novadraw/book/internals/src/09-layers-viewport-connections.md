# 9. 图层、视口与连接

图层、视口和连接看似是三个功能，实质上都依赖跨节点派生状态、坐标传播和明确的更新
顺序。

本章解释：

- 语义图层与普通容器的关系；
- freeform 内容范围如何从子节点派生；
- viewport、range model、scroll pane 与 scalable pane；
- 滚动和缩放为何仍是普通坐标变换；
- Anchor、SceneQuery、Router 和 Connection 的分工；
- 依赖追踪、分组路由、自环与 unresolved 状态。

核心结论：

> 跨节点能力不应缓存未知来源的几何；它们必须通过可追踪查询读取稳定场景，并在依赖
> 变化后重新计算。

本章应使用节点移动、视口滚动和缩放三个事件，展示连接路径、反馈图层和可见区域如何
在同一帧重新投影。
