# 13. 原子性、故障与可验证演进

框架的长期质量取决于它在失败、取消、扩展和优化后仍能维持相同不变量，而不只是正常
路径能够运行。

本章解释：

- prepare rejection 与 commit failure；
- 原子提交、补偿与半发布结构；
- recoverable error、retry、suspended 和 faulted；
- 稳定通知与可观察状态；
- 契约测试、headless replay 和平台验收；
- 性能基线、复杂度预算和证据驱动优化；
- 架构增量与公共 API 稳定性。

核心结论：

> 只有能够描述失败前后状态、提供确定性证据并保持扩展边界的变化，才是可持续的框架
> 演进。

全书在本章汇合：状态所有权决定原子边界，固定管线决定失败位置，身份模型决定清理，
验证体系证明这些约束在实现变化后仍然成立。
