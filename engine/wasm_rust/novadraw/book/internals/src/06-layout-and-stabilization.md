# 6. 测量、布局与稳定化

布局不是一次性地给子节点赋坐标，而是在约束、内容和派生依赖变化后重新建立稳定几何
的过程。

本章解释：

- intrinsic size、最小尺寸、最大尺寸和尺寸提示；
- 测量与排列的职责分离；
- 布局约束为什么属于父子关系；
- LayoutSnapshot 与 LayoutOutput；
- 为什么布局器应纯计算，Runtime 负责应用结果；
- invalidation、工作列表、稳定 epoch 与收敛条件。

核心结论：

> 布局器计算候选几何，Runtime 验证并提交；稳定化结束前，场景不能对外宣称完成。

本章应比较固定坐标、填充、流式、网格和自由范围布局的约束差异，但不把具体布局器
写成互不相关的 API 清单。
