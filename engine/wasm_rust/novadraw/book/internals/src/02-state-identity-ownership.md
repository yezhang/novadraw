# 2. 状态、身份与所有权

任何复杂图形系统最终都会遇到同一个问题：多个模块看起来都需要“知道”同一对象，但
不能同时成为它的事实所有者。

本章解释：

- 权威状态、派生状态、缓存与临时状态；
- `ModelId`、`EditPartId`、`FigureId` 的身份域；
- 代际身份如何防止槽位复用后的悬空引用；
- detached、build、attached、drive 生命周期；
- 为什么挂载后只暴露短生命周期修改入口；
- 为什么跨系统关系应保存稳定身份，而不是对象引用。

核心结论：

> 状态可以有多种表示，但只能有一个写入权威；身份可以互相映射，但不能互相替代。

本章应使用所有权表、身份关系图和对象生命周期图，并通过“删除后槽位复用”“撤销后
视图重建”等反例说明错误身份为何危险。
