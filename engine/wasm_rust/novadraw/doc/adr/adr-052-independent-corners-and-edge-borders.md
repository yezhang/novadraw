# ADR-052：逐角圆角与矩形分边描边

类型：`architecture-decision`

状态：`accepted`（2026-10-27 用户批准实施）

## 契约

Core 提供可供外部 Figure 复用的不可变 `ShapeContour`。矩形输入按左上、右上、
右下、左下指定二维半径；多边形按顶点顺序指定圆形半径。旧
`corner_dimensions` 仍表示 Draw2D 的圆角宽高，不改成半径。

矩形按相邻半径之和统一缩放有效半径，保留请求值。多边形圆角与相邻边相切，
按相邻切点距离统一缩放；允许凹角，拒绝有圆角的自交、重复顶点和零面积路径。
零半径保持原有直边行为。非法值、数量不匹配和派生非有限几何返回结构化错误。
点和半径通过 `ReplacePolygonGeometry` 一起替换，避免插删后角身份错位。
原有构建期 `add_point` 保持直边语义，并清除此前圆角配置。

矩形描边配置按上、右、下、左提供继承、指定颜色或关闭。第一批统一线宽，
轮廓保持在 bounds 内。相邻两边都开启时，每个圆角在参数角中点处分给相邻边；
边框区域由外轮廓、内轮廓和共享分界组成，颜色不重复覆盖。
2026-10-27 自由端修订：相邻边关闭时，开启边使用 Butt 平齐截面，停在该边的
直线切点，不向关闭边形成圆角接合；零半径时切点就是矩形顶点。因此缺底边、
下角为零的矩形左右描边完整延伸到底部，以水平截面结束，不保留斜切缺口。
判定依据为边是否存在；显式透明颜色仍表示已配置的边，不因透明度变化改变接合。
内轮廓消失时，边框分区延伸到中心，不产生负尺寸。分边模式为实线；
原有 dash/cap/join 继续用于统一描边。

GPU 验证确认：单独 AA 填充各分区会使半透明交界变淡。混合颜色或关闭边时，
整个 ring 共用一次 AA path clip，分区使用已有 `AntialiasMode::Off` 进行像素
中心归属；同色四边直接填充完整 ring。颜色分界保持清晰，外/内轮廓保留 AA，
不新增 Graphics primitive。调用方明确关闭 AA 时按原请求绘制分区。

分区直线的设备中心扫描必须按统一端点方向求交；反向计算共享边的浮点误差
可能造成一像素缺口。椭圆圆角的分区线按内、外圆角参数中点延长，不固定为
45 度直线。

圆角矩形、多边形和三角形使用相同轮廓来源绘制与命中；命中不受颜色或边开关
影响。子节点 clipping 策略不随圆角自动改变。已有 uniform 圆角路径保留兼容。
`RectangleBorder` 的新 builder 返回 `RectangleShapeBorder`，保留旧 struct literal
兼容性；insets 与画出的边仍分别配置。

## 更新与扩展

新配置使用现有 `FigureComponentUpdate`，prepare 验证输入，commit 原子替换，
同值无 revision、通知或 damage。不增加 Runtime concrete dispatch、渲染命令
或后端类型分支。颜色变化仅 repaint，几何变化更新命中和 damage。
稳定输入下轮廓可由 Figure 保存并共享；bounds 变化时重建派生轮廓。
validation 只写派生轮廓缓存，不把拉伸后的 NodeState bounds 写回矩形的
构建期 bounds，也不改写多边形的原始点与 bounds，以免改变固有尺寸与后续
布局测量。多边形按实际尺寸缓存轮廓；稳定尺寸的绘制和命中共享同一 Arc。

外部消费者证据：独立集成测试直接使用公开轮廓构造自定义 Figure；独立 Native
组合样例用已有 Figure、Label 和 child tree 构成标题区域，不向 Core 添加标题
容器、布局或专属类型。

## 成本与验证

矩形轮廓与边框固定四个区域；多边形输出及存储为 O(n)，有圆角时 simple-polygon
预检为 O(n²)，仅在输入变化时执行。复用现有 Path 与 Kurbo 内部几何，不新增
依赖、字体或图片。测量稳定轮廓访问与构建成本，并用同配置 release 产物比较
体积；源码行数不作为包体积证据。
自由端路径根据解析后的边启用 mask 派生；几何对象只保留最近一种 mask 的
不可变路径缓存。颜色变化不重建该路径，mask 变化时替换缓存，原有已借出的 Arc
保持有效。缓存为对象所有，不使用全局状态，不预建全部 16 种组合。

混合边的像素归属复用 backend 的 Off coverage 准备：首次准备受设备尺寸、变换
和现有预算约束，稳定几何可复用 backend 缓存。必须测量该路径，不能只报告
Core 轮廓访问成本。超预算沿用已有结构化失败，不绕过预算或扩张原生能力声明。

验证覆盖逐角/凹角/超大半径、边开关与半透明分界、退化输入、typed update
同值及失败原子性、外部 Figure 与独立样例。平台像素支持声明以实际 runner
证据为准，未运行的平台不外推。

Draw2D 参考仅限 `org.eclipse.draw2d`：RoundedRectangle 使用统一 corner dimensions，
Polygon/Triangle 使用直边顶点；逐角和分边为本项目扩展，不宣称 Java 原 API 对等。
