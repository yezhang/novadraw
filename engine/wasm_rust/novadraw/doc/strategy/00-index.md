# 产品与商业策略

类型：`product-strategy`

本目录承载 Novadraw 的产品定位、市场判断、商业模式和商业验证方法。

此处内容是决策输入，不定义运行时架构、API 契约或里程碑状态。相关权威内容分别以
`design/`、`parity/`、`adr/` 和 `roadmap/` 为准。

## 使用原则

- 区分外部事实、战略判断、商业假设和验证结果。
- 价格、市场规模和客户意愿在获得真实客户证据前均视为假设。
- 商业目标需要改变架构时，必须通过 `design/` 或 ADR 正式决策。
- 商业进度需要改变里程碑时，必须更新 `roadmap/00-index.md`。
