# R8 迁移前性能基线

类型：`verification`

本文记录 R8 canonical 名称迁移前的无窗口 release 基线。原始 JSON 位于本地
`target/performance/r8-baseline.json`，不提交构建产物。

## 环境

| 项目 | 值 |
|---|---|
| 基线提交 | `949e798c62612e0af83abcde5136aa5b4e274262` |
| 操作系统 | macOS 14.7.8 (23H730) |
| CPU | Apple M1 Pro |
| 架构 | aarch64 |
| Rust | rustc 1.94.1 (e408947b, LLVM 21.1.8) |
| Profile | release |
| 预热 / 采样 | 1 / 7 |

## 执行

```bash
cargo run --release -p r8-perf -- \
  --report=target/performance/r8-baseline.json
```

`r8-perf` 不创建窗口，也不测 GPU present。它测量 FigureTree 构造、遍历、命中、
命令录制和 viewport 合成的 CPU 路径。

## 结果

| 场景 | Setup | Min | Median | P95 | 输出 |
|---|---:|---:|---:|---:|---:|
| `large_tree_render_4096` | 3.052 ms | 2.369 ms | 2.481 ms | 2.566 ms | 53,258 commands |
| `large_tree_hit_test_4096` | 2.603 ms | 22.250 us | 22.667 us | 24.541 us | root hit |
| `deep_tree_render_10000` | 297.103 ms | 9.404 ms | 10.021 ms | 11.040 ms | 129,997 commands |
| `text_recording_1000` | 0.619 ms | 0.437 ms | 0.476 ms | 0.486 ms | 13,010 commands |
| `viewport_render_1024` | 0.571 ms | 0.375 ms | 0.499 ms | 0.657 ms | 13,346 commands |

说明：

- large-tree hit-test 使用树内但所有 child 外的点，测量遍历 4,096 个 child 后命中根的路径；
- deep-tree 使用允许的 10,000 层边界，继续走受保护的递归渲染主线；
- text 场景只测 Figure 遍历与文本命令录制，不代表 glyph shaping 或 GPU 文本性能；
- viewport 场景包含 clip、view location 和 1.5 倍 scalable transform。

## 回归判定

重命名批次不应改变算法，输出 command 数必须完全一致。

计时受系统负载影响。若任一场景 median 比本基线高 15% 以上：

1. 在同一机器、工具链和 release 配置下再完整运行三次；
2. 比较三次 median 的中位数；
3. 若仍高于 15%，停止该批次并定位原因，不通过扩大阈值放行。

不同机器的结果只能作为独立基线，不能与本文数值直接比较。
