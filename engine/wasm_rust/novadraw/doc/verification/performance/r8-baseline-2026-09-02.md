# R8 迁移前性能基线

类型：`verification`

本文记录 R8 canonical 名称迁移前的无窗口 release 基线。原始 JSON 位于本地
`target/performance/r8-baseline.json`，不提交构建产物。

## 环境

| 项目 | 值 |
|---|---|
| 基线提交 | `949e798c62612e0af83abcde5136aa5b4e274262` |
| 操作系统 | macOS 14.7.8 (23H730) |
| CPU | Apple M1 Pro |
| 架构 | aarch64 |
| Rust | rustc 1.94.1 (e408947b, LLVM 21.1.8) |
| Profile | release |
| 预热 / 采样 | 1 / 7 |

## 执行

```bash
cargo run --release -p r8-perf -- \
  --report=target/performance/r8-baseline.json
```

`r8-perf` 不创建窗口，也不测 GPU present。它测量 FigureTree 构造、遍历、命中、
命令录制和 viewport 合成的 CPU 路径。

## 结果

| 场景 | Setup | Min | Median | P95 | 输出 |
|---|---:|---:|---:|---:|---:|
| `large_tree_render_4096` | 3.052 ms | 2.369 ms | 2.481 ms | 2.566 ms | 53,258 commands |
| `large_tree_hit_test_4096` | 2.603 ms | 22.250 us | 22.667 us | 24.541 us | root hit |
| `deep_tree_render_10000` | 297.103 ms | 9.404 ms | 10.021 ms | 11.040 ms | 129,997 commands |
| `text_recording_1000` | 0.619 ms | 0.437 ms | 0.476 ms | 0.486 ms | 13,010 commands |
| `viewport_render_1024` | 0.571 ms | 0.375 ms | 0.499 ms | 0.657 ms | 13,346 commands |

说明：

- large-tree hit-test 使用树内但所有 child 外的点，测量遍历 4,096 个 child 后命中根的路径；
- deep-tree 使用允许的 10,000 层边界，继续走受保护的递归渲染主线；
- text 场景只测 Figure 遍历与文本命令录制，不代表 glyph shaping 或 GPU 文本性能；
- viewport 场景包含 clip、view location 和 1.5 倍 scalable transform。

## 回归判定

重命名批次不应改变算法，输出 command 数必须完全一致。

计时受系统负载影响。若任一场景 median 比本基线高 15% 以上：

1. 在同一机器、工具链和 release 配置下再完整运行三次；
2. 比较三次 median 的中位数；
3. 若仍高于 15%，停止该批次并定位原因，不通过扩大阈值放行。

不同机器的结果只能作为独立基线，不能与本文数值直接比较。

## R8.1 Canonical 定义反转复测

R8.1 完成 `FigureId / FigureNode / FigureTree` canonical 定义反转后，所有场景
command 输出与基线完全一致。

首次复测的 deep-tree median 高于 15% 噪声阈值，因此按上述规则追加三次完整运行。
三次 median 的中位数如下：

| 场景 | 基线 Median | R8.1 Median-of-medians | 变化 |
|---|---:|---:|---:|
| `large_tree_render_4096` | 2.481 ms | 2.265 ms | -8.7% |
| `large_tree_hit_test_4096` | 22.667 us | 20.750 us | -8.5% |
| `deep_tree_render_10000` | 10.021 ms | 9.009 ms | -10.1% |
| `text_recording_1000` | 0.476 ms | 0.518 ms | +8.8% |
| `viewport_render_1024` | 0.499 ms | 0.343 ms | -31.3% |

没有场景超过 15% 回归阈值，R8.1 性能门禁通过。该结果只说明本批命名重构没有
引入可测 CPU 回归，不作为跨机器性能结论。

## D1 核心公共协议收口复测

D1 首次复测发现样式继承在渲染时为每个 Figure 重新遍历完整祖先链，并为默认样式
额外录制 alpha command。10,000 层深树因此退化为 O(n²)，median 从 10.021 ms
上升到约 720 ms。修复后，绘制仅将节点 local style override 写入 Graphics state，
由状态栈自然向子节点继承；公共 `resolved_style` 查询语义保持不变。

修复后所有场景的 command 输出与 R8.0 基线完全一致。首次复测的 deep-tree median
略高于 15% 阈值，因此按规则追加三次完整运行。三次 median 的中位数如下：

| 场景 | 基线 Median | D1 Median-of-medians | 变化 |
|---|---:|---:|---:|
| `large_tree_render_4096` | 2.481 ms | 2.437 ms | -1.8% |
| `large_tree_hit_test_4096` | 22.667 us | 21.666 us | -4.4% |
| `deep_tree_render_10000` | 10.021 ms | 10.713 ms | +6.9% |
| `text_recording_1000` | 0.476 ms | 0.432 ms | -9.2% |
| `viewport_render_1024` | 0.499 ms | 0.370 ms | -25.8% |

没有场景超过 15% 回归阈值，D1 性能门禁通过。原始 JSON 位于本地
`target/performance/d1-final-fixed-{1,2,3}.json`。
