# D1.1 Selection 外移手工验收

类型：`verification`

状态：`approved`

本流程验证 selection 已由 editor 层拥有，同时保持原有选择反馈、坐标和场景生命周期
行为。它不验证 GEF SelectionProvider 或多选协议。

## 1. 启动

```bash
cargo run -p editor-app
```

## 2. 初始选择反馈

1. 按 `1`，确认青色孙节点外存在黄色选择轮廓。
2. 按 `2`，确认透明根场景中的青色孙节点具有相同轮廓，且没有额外坐标偏移。
3. 按 `5`，确认青色孙节点具有黄色选择轮廓。

## 3. 变换跟随

1. 保持场景 `5`。
2. 连续按 `T`。
3. 确认图元和选择轮廓同步移动。
4. 确认旧位置没有残影。

## 4. 点击选择

1. 按 `9`。
2. 点击蓝色探针内部，确认出现黄色选择轮廓。
3. 按下后拖出探针再释放，确认轮廓仍跟随原目标且 capture 正常结束。
4. 点击无交互目标区域，确认不会产生错误选择反馈。

## 5. 场景隔离

1. 在场景 `9` 选中探针。
2. 切换到场景 `1`，确认只显示场景 `1` 的初始选择。
3. 切换到场景 `0`，确认没有遗留选择轮廓。

## 6. 通过条件

- selection 状态不泄漏到其他场景；
- 轮廓位置与目标 Figure 的实际投影一致；
- 点击、拖拽、capture、focus 和 hover 行为无回归；
- resize 和场景切换后无旧轮廓残影。
