# ADR-014 D4.4 实现记录

类型：`verification`

日期：2026-09-10

状态：`complete`

## 本批范围

- Runtime topology 新增 `try_set_contents`、`try_add_figure`、
  `try_remove_figure` 与 `try_reparent`，保留旧 convenience API。
- topology 错误保留 ForeignRuntime、UnknownOrDisposedFigure、
  SyntheticRootOperation、InvalidParentRelation、LayeredParent 与具体
  GraphMutationError，不再统一坍缩为 null、false 或 Rejected。
- `TextLayoutParts` 与 `TextLayout::from_parts` 提供外部文本引擎的受校验构造入口；
  校验字体、约束、总体和行指标、glyph run 及 UTF-8 visible range。
- Parley 与 `with_visibility` 复用相同不变量检查；独立非 Parley 引擎已生成非空
  GlyphRun IR，并通过 Runtime 和 NdCanvas 消费。
- `FramePreparation` 区分 Ready、Idle、Suspended、AwaitingCompletion 与 Error；
  原 `prepare_submission -> Option` 作为兼容入口保留。
- RenderCommand 声明 GlyphRuns/ImageResources 要求；Runtime 在最终 command stream
  冻结后返回永久 `UnsupportedRenderCapability`，不进入 in-flight 或 Retry。
- RenderOutcome 增加结构化 Unsupported，Web Canvas2D 防御性拒绝不支持的 glyph/image；
  Native editor 不对永久 unsupported 状态循环请求 redraw。
- `BackendSessionGate` 要求首次 session、同域新 generation 和跨 Runtime 接管均以
  Snapshot 建立基线；缺基线 Delta 与同域 stale generation 不改变 active session。
- Vello 与 Web Canvas2D backend 使用同一 session gate。DemoApp 场景切换验证新
  Runtime 使用不同 namespace，并以 Snapshot 完成串行接管。
- 既有 Manhattan group failure 测试已覆盖整组 unresolved、旧 route/reservation
  清理和原子恢复，本批未重复实现路由逻辑。
- 新增 `FigureComponentUpdate` 两阶段协议：外部更新先从只读 typed Figure 产生 owned
  prepared value，再由 Runtime 提交；不暴露 `&mut dyn Figure` 或任意 mutation
  closure。
- 每个 FigureNode 持有独立 component revision；Runtime 在 prepare 前验证
  namespace、attached 状态、具体类型和 revision capacity，成功后统一递增 revision。
- `PreparedFigureUpdate::new` 默认声明 layout/geometry/paint 全失效，调用方只能通过
  显式构造器窄化；Runtime 统一记录旧/新 damage、布局失效和连接依赖失效。
- `ComponentUpdateError` 区分 Runtime、wrong type、revision exhausted 与组件拒绝；
  prepare 失败不改变 Figure、revision 或 pending work。
- prepare/commit 及其触发的 lifecycle invalidation 均位于 panic guard 内；panic
  原样传播并将 Runtime 标记为 faulted，后续 frame 返回 Faulted。
- 独立外部 `BadgeFigure` 验证私有文本、测量宽度和 paint snapshot 更新，无需 Runtime
  增加具体 Figure 类型分支。
- 公共 Figure/Layout/Border/Widget、Connection、Resource、Text 与 Focus mutation
  统一进入 Runtime panic guard；扩展 panic 原样传播并将 Runtime 置为 faulted，
  后续 `Result` mutation 返回各域结构化 Faulted，旧 bool convenience 返回 false。
- `MeasureConstraints` 与 `FigureMeasurement` 将宽高约束及 baseline 暴露给
  `Figure`/`LayoutSnapshot`；外部 Figure 和 LayoutManager 已验证父宽度测量、
  单次 arrange 与同约束 Parley GlyphRun IR 绘制。
- 新增 `NotificationRecord { source_epoch, sequence, effect }` 与
  `ObservationListener`；历史事件保留因果 FIFO 和发布 source epoch，listener 查询只读取
  flush 时的 `StableSceneQuery`。有未发布工作时 `Runtime::stable_query` 返回 NotStable。
  submission、legacy incremental frame 与 full-frame recording 共用该发布语义；
  notification-only 更新在 Idle preparation 中完成发布。
