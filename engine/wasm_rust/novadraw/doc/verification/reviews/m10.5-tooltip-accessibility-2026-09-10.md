## Native 视觉验证

命令：

```bash
cargo run -p widgets-app -- --screenshot=Tooltip_Boundary_Visual
```

输出：

```text
target/visual-verification/screenshots/
  widgets-app_Tooltip_Boundary_Visual_<timestamp>.png
```

截图已复核：

- Tooltip 非空；
- bottom-edge source 触发上翻；
- 右边界 clamp 后未越出 surface；
- popup 与目标之间保留间距；
- Label、Button 与背景无错位或残影。

截图模式会忽略真实窗口 pointer/key 输入，避免机器当前鼠标位置覆盖场景预置状态。
`Tooltip_Accessibility` 保持默认 500ms delay，用于真实人工交互；截图预热只存在于
独立的 `Tooltip_Boundary_Visual` 场景。

## Web 浏览器验证

地址：

```text
http://127.0.0.1:4173/?backend=vello&build=m105
```

Chrome/WebGPU 实测：

- `data-ready=true`；
- `data-backend=vello-webgpu`；
- Widgets Tooltip/Accessibility 场景可达；
- accessibility DOM 含 4 个语义节点：
  `Tooltip source and accessibility roles`、`Inherited tooltip`、
  `Accessible action`、`Bottom edge`；
- hover canvas 后 Tooltip 文本为 `Inherited from the scene root`；
- Tooltip DOM 为 `display:block`，边界非零；
- Console 无错误；
- Tooltip 超时后按契约隐藏。

浏览器截图工具连续两次超时；Web 结论使用 DOM/AX、非零 Tooltip bounds、WebGPU frame
状态和 Console 证据，不把工具超时记为产品失败。Native/Vello 截图提供当前像素证据。
