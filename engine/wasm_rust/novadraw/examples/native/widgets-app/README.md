# Widgets App

M10.4 Clickable, Button, and Toggle verification.

```bash
cargo run -p widgets-app
cargo run -p widgets-app -- --screenshot-all
cargo run -p widgets-app -- --screenshot=Button_States
```

The scenes cover normal, rollover, pressed, focused, disabled, and selected
visual states. `Interactive_Widgets` supports pointer activation, drag-out
cancellation, focus, Enter, and Space.
