# ADR-059 B1：通用语言映射准入

类型：`implementation-verification`

日期：2026-11-02。能力归属：Core（`novadraw`）文字引擎的
Harfrust 0.3.2 生产依赖。`api_semantics`：`text.flow`、`text.interaction`。
状态：本子片已实现并通过定向核验；B1 和默认启用仍未关闭。

本片接续[私有语言标签准入](text-stages-b1-private-language-2026-11-02.md)，
补齐主语言表、扩展语言和复合标签的查找与拒绝通道。
`en-US`、`zh-hant-mo`、`und-fonipa` 等输入可以构造受准入约束的计划，
无需有效 `hbot` 才能进入语言映射。

## 普通入口与准入入口共用有序规则

锁定的生成表包含九条通用变体规则和按首字节分组的地区、文字与旧语言规则，
共 148 条。新增 `tag_rules.rs` 保留每条条件、分组、先后顺序和输出 tag 顺序，
两类入口共用规则解释与字节比较内核。原生成函数只编入测试，
用于独立核对规则输出；生产路径不再维护两份匹配算法。

规则遇到首个匹配即返回。`-fonipaa-fonipa` 的首个字符串匹配不满足 subtag
边界时，仍继续寻找后面的匹配；行为与原 `match_indices` 的非重叠搜索一致。
中文地区规则同时保留前缀匹配、后续 subtag 搜索和短路条件。
构造语言标签时，每条规则最多输出两个 tag，调用时输出集合为空，
因此使用三槽 inline 存储，无需堆分配。

主语言表继续采用相同的比较关系，显式二分查找覆盖每次字符串扫描与比较。
匹配后回退到同语言的首个条目，按原表的容量与尾槽约束输出。
三字节未登记语言继续转成大写 OpenType tag；没有匹配时可以返回空语言标签。
这些都是完整映射结果，不代表未知算法路径。

## 每次访问先计费

| 操作 | 执行前费用 |
|---|---|
| 规则选择 | 访问实际规则、判别值和字符串视图；只扫描所选首字节分组 |
| subtag 搜索 | 共用八字节跳过与精确窗口搜索；各轮字节读取、临时字宽复制、清理及边界读取分别覆盖 |
| 精确比较 | 输入窗口和 needle 的读取分别准入，包含重复比较；不使用未经证明的字符串 searcher |
| 前缀与完整相等 | 先读取长度，分别覆盖两个比较范围；短输入保持原先的失败结果 |
| 主语言二分查找 | 每个表项、两个主语言前缀定位、比较字节与重复条目回退均先准入 |
| tag 输出 | 先付静态四字节读取、输出写入和最终清理费用 |
| 计划语言值 | 沿用已验证的 Language inline／spill 复制与 fallible 容量预留 |

Language 构造时已经完成 ASCII 大小写和下划线规范化，
其非空前缀可以直接映射，不再申请临时 Language 后重新复制与规范化。
空前缀继续跳过通用映射，与原 `Language::from_str` 拒绝空字符串的结果一致。

本片同时补齐共用窗口搜索中 needle 的重复读取费用。
历史私有语言报告与 receipt 对应其当时的源码；当前费用以本片 receipt 为准。
work 仍表示输入字节或元素访问，allocation 仍表示完整新增容量槽位。
没有按字符长度指定经验倍数，也没有扩大下层生产依赖补丁范围。

## 拒绝后不发布计划

每个规则匹配、表项查询和输出写入的拒绝立即传播原始错误 source。
不会改选后续规则，也不会调用普通入口补做。
计划只在全部构造成功后返回；失败丢弃本次候选。
本片未转移外部 UnicodeBuffer，实际 shaping 的 buffer 恢复仍须单独验收。

外部消费者用十一组标签逐准入点拒绝，
覆盖私有标签、普通主语言、中文地区、边界不匹配后继续搜索、
扩展语言、未登记语言和空私有值。
每次检查严格 trace 前缀、原始 source、同样的重试 trace
以及下一次普通计划的 glyph 输出。
既有粘滞预算测试保留。

## 定向验证

新增源码测试核对全部 148 条复合规则的成功、边界与截断输入，
并将主语言表的全部条目、六种后缀与两种扩展形式和锁定内核对照。
外部输入矩阵包含每条规则的代表输入及十八组边界输入和长前缀，
共 167 种语言；结构字体和真实字体共同覆盖语言选择后的输出。
glyph 观察使用普通 shaping 驱动，核对计划选择产生的可观察结果，
不表示实际 shaping 已接入准入。

最终补丁重放 receipt（`target/verification/text-stages-b-2026-11-02/general-language-verification.json`）
从原始归档重放十份冻结补丁，再追加本片。
四个既有源码文件改动，新增一个规则模块，其他 75 个源码文件逐字节保持；
验证结束再次核对全部 80 个生产源码文件。148 条规则的条件、
分组、先后顺序和 tag 输出全部与冻结生成表一致。

| 验证范围 | 结果 |
|---|---|
| 原始／生产 Native／portable | 既有计划矩阵各 39,744 份、布局表矩阵各 50,688 份、私有语言矩阵各 6,720 份、通用语言矩阵各 24,048 份观察分别一致，并核对 SHA-256 |
| 外部 Native／portable | 各 36 项通过，覆盖新增通用语言、逐点拒绝与既有预算粘滞 |
| 私有 Native／portable | 各 200 项通过，包括全部规则与主语言表对照 |
| Core Native／Wasm | `novadraw --lib` check 通过 |
| Wasm 消费者 | portable library 构建通过，未执行 Wasm 测试 |
| Clippy／格式／脚本 | Native library／成本采样与 portable library 无 warning；新增 Rust 格式与 Python 语法检查通过 |

## 计划成本

四模式成本 receipt（`target/verification/text-stages-b-2026-11-02/general-language-cost-summary.json`）
保存三种语言、四种模式各 1,000 次有效样本，共 12,000 次，
每组预热 100 次，模式逐样本轮换。
Native release 使用 Inter，语言解析、数据缓存与 Shaper 配置在计时之外；
成功计划释放在计时之外，最后点拒绝包含候选清理。

| 语言输入 | 普通 P95（µs） | 空回调 P95（µs） | 计数 P95（µs） | 最后点拒绝 P95（µs） |
|---|---:|---:|---:|---:|
| `en-US` | 4.459 | 6.875 | 7.209 | 7.416 |
| `zh-hant-mo` | 4.209 | 6.417 | 6.792 | 7.000 |
| 1,024 字节前缀后接 `fonipa` | 5.333 | 7.792 | 9.084 | 9.584 |

成功计数分别记录 work 5,996／6,741／28,941，
allocation 196／206／1,231，回调 1,324／1,308／3,545 次。
费用包含整份计划。最后点拒绝与成功的累计 work／allocation 相同，
该点为零长度 feature 复制的准入；候选释放仍包含在拒绝计时中。

原始／生产普通成本 receipt（`target/verification/text-stages-b-2026-11-02/general-language-ordinary-cost-summary.json`）
采用相同普通 API 源码、相同 feature，三轮轮换执行顺序，
各组各 1,000 次、预热 100 次，共 18,000 个样本。

| 语言输入 | 原始 P95 三轮范围（µs） | 生产 P95 三轮范围（µs） |
|---|---:|---:|
| `en-US` | 4.417–4.792 | 4.000–4.208 |
| `zh-hant-mo` | 4.333–4.375 | 3.958–4.000 |
| 1,024 字节前缀后接 `fonipa` | 10.458–10.542 | 5.083–5.084 |

该长前缀场景的普通计划构造耗时下降，
对应变化包括去掉临时语言复制和共用有明确边界的字节搜索。
本轮未做逐项消融，不能把全部收益归给某一个改动。
`before-needle-read-fee-*` 保留补齐 needle 费用前的中间样本。

本机负载未控制，长尾保留。结果只描述计划构造，
不能推导 Core 端到端排版、实际 shaping、GPU 或宽度复用已经通过验收。
成稿已分别核对事实、技术因果和中文表达，未取得独立评审结论。
中文机械扫描初稿与成稿均为零命中，记录见
复核 receipt（`target/verification/text-stages-b-2026-11-02/general-language-chinese-review.json`）。
