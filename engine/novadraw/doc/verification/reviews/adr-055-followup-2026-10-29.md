## 新增契约

`p2_e03_container_editing_contract` 新增两项行为测试。

`retired_acquired_feedback_rejects_cleanup_before_build_for_both_tools` 使用真实
移动／创建 Tool 获取反馈，再经公开宿主入口提前退休其中一项。
release 的 overlay 准入拒绝未拥有的旧 Figure，保留未完成手势，
不构造命令、不改变模型 revision、不产生 history，Viewer 没有进入 fault。
这是已取得反馈的清理准入拒绝，不是 Core revision 耗尽。

`stationary_creation_recomputes_after_dual_axis_autoexpose_scroll_zoom_and_resize`
通过实际创建 Tool 完成双轴 auto-expose、显式 scroll、zoom 和 resize。
期间不增加 pointer move；释放按最新目标映射计算 bounds，
保持 contents 域创建起点，创建只构造一次命令、不查询移出资格，
undo/redo 恢复相同约束。

CE-15 的两种 Tool lifecycle panic 已有覆盖。
Core 私有单测 `s06_late_disposal_prepare_rejection_keeps_retired_prefix_and_live_suffix`
证明真实 connection revision 耗尽时的退休前缀／存活后缀。
该私有注入不能经现有 Editor API 使用；两种容器 Tool 的 revision 耗尽端到端
场景仍缺证据。未新增公共测试 hook，也不把提前退休的准入拒绝当成该场景。

## 成本测量与修复

新增默认忽略的 scaling test，显式在 Native release 执行。
每阶段 32 个样本，包含 16／64 个不同源父，以及一个源下的 32／2048 个后代。
资格查询数断言为实际源父数；候选期间 children 读取为零，
每次有 revision 的同步仍读取全部节点。

测试专用 System allocator 包装只记录当前线程的成功 alloc／alloc_zeroed／realloc：
bytes 为申请尺寸累计，包含 realloc 新尺寸；不是存活内存、峰值或 RSS。
初始化、undo 和样本容器自身的分配不在对应阶段内；反馈与完整提交包含清理。
正式库不增加 allocator、默认 feature、依赖或公开 API。

原始样本见[修复前](../evidence/p2-e03-container-scaling-2026-10-29.log)与
[修复后](../evidence/p2-e03-container-scaling-after-2026-10-29.log)。
macOS/aarch64，Rust 1.96.0，同一 fixture、release 配置与采样器。
后台负载未受控，两次采样分别发生在其他编译任务可能活动的时段；
时间差只作本次观察，不作为稳定提速承诺。分配结果可直接对应源码变化。

瓶颈是宽容器中逐 child 的无变化重排：
Runtime 校验每次复制完整 child_order，再线性查找 index；
Viewer 同步还对每个旧 child 线性扫描 desired，对每个未变化 Part 再查找索引。
修复保留 namespace、live、attached、parent、layer 和 index 校验，
用直接 parent／child_count 与私有 `child_at_index` 查询拒绝或识别无变化；
Viewer 用身份集合检查保留项，未变化 Part 顺序直接比较当前位置。
真实重排继续使用既有提交与 damage 路径，内置和外部 Figure 同样受检。

## 定向审阅与剩余工作

已复核 `container/service.rs` 的共享批次、源父分组、候选几何和资格验证，
两种 Tool 的 release 清理／构造顺序，以及 Viewer 目标排除和同步重排。
本轮修复无需改变 ADR-055 的坐标、事务或开放协议。

ModelSnapshot 仍为全量捕获，所有 Part 仍调用 refresh；
大源换父仍退休并重建整个投影子树。完整提交包含夹具命令复制完整模型，
因此不能将剩余 18.159 ms 全部归给引擎。
反馈创建／清理仍有全 registry 扫描成本，handler 内部扫描未单独计数。
这些结果支持下一轮先拆分模型复制、投影重建、反馈与稳定化，再评审增量同步；
当前不增加未经评审的事件差量协议或全局缓存。
