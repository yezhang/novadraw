## 配对范围与复现

`4f104633fcb7c555d165cc20d2902ab554aa6d4a` 加保存的工作区差异。
消费者 manifest、lock 和驱动器保持相同字节，lib 只适配公共接口和字体 descriptor。

[源码收据](../evidence/p2-s08-d-reproduction-2026-10-29.json)。

release 配置统一为 opt-level=s、LTO、单 codegen unit、panic=abort、strip。

两组验证配置边界，不能据此声称动画可裁剪。

Native 默认 gzip 增加 9,352 字节，Wasm 默认 gzip 增加 7,292 字节。

## CPU 工作负载

每配置十轮交替执行迁移前后产物。每模式先预热一次，
再采集 101 个样本，每样本执行 120 次后续操作。
P50／P95 是每轮批次分位数，最终表取十轮中位数。
计时包括 Runtime／Border 初始化和 teardown，
allocator 记录请求次数与请求字节，realloc 按请求的新尺寸计数。

| 模式 | 工作量 |
|---|---|
| 稳定帧 | 一个根和 64 个矩形，共享两层 Compound Border；初始化后重复准备，允许 Idle |
| 连续 resize | 同一场景，每次更新 64 个节点的宽度，再准备并确认提交 |
| 继承样式帧 | 同一场景，交替修改根 foreground，再准备并确认提交 |
| Border 构造 | 每次创建两条 Line、两层 Compound 和一条 Margin，查询组合指标 |
| Border 指标 | 每样本构造并冻结一次，随后查询 120 次 |
| 固定录制 | 同上，每次通过公开 PaintContext 录制固定尺寸 |
| 变宽录制 | 同上，每次使用递增宽度录制 |
| 字体样式 | 两节点，交替字号、颜色并读取子节点继承字体和 alpha |

字体样式的迁移前入口每次设置前解析文本，继承查询后再次解析；
迁移后保存 descriptor，继承查询直接读取 descriptor。
这属于 S08-A 的目标变化，其他 Runtime 模式保持同一工作量。

## 最终成本结果

环境为 macOS 14.7.8、arm64。最终采样从 UTC 13:30:15 至 13:36:47，
全部原始轮次、分位数范围和产物 SHA-256 见
[最终收据](../evidence/p2-s08-d-cost-receipt-final-2026-10-29.json)；
stdout 见[最终采样日志](../evidence/p2-s08-d-cost-paired-final-2026-10-29.log)。
下表为十轮中位数，单位 ns，计时口径为整个批次。

| 配置／模式 | 迁移前 P50／P95 | 迁移后 P50／P95 |
|---|---|---|
| 默认／稳定帧 | 1,438,708／1,616,604.5 | 1,479,312／1,666,604 |
| 默认／连续 resize | 31,537,437.5／33,630,354 | 30,786,542／33,247,520.5 |
| 默认／继承样式帧 | 23,144,083.5／24,831,875 | 22,675,104.5／25,087,833.5 |
| 默认／Border 构造 | 25,604／27,021 | 38,375／41,375.5 |
| 默认／Border 指标 | 2,584／3,083.5 | 2,833／3,062 |
| 默认／固定录制 | 95,479／110,333.5 | 94,687.5／104,625 |
| 默认／变宽录制 | 96,854／110,250 | 94,333.5／109,417 |
| 默认／字体样式 | 156,771／192,854 | 153,292／192,375 |
| 无默认／稳定帧 | 1,398,333.5／1,525,979 | 1,419,146／1,538,958.5 |
| 无默认／连续 resize | 29,024,271／31,286,813 | 29,580,062.5／31,969,249.5 |
| 无默认／继承样式帧 | 21,846,000／24,331,541.5 | 21,546,708.5／24,342,312.5 |
| 无默认／Border 构造 | 23,958／25,541.5 | 37,708.5／39,562.5 |
| 无默认／Border 指标 | 2,646／3,271 | 2,937.5／3,063 |
| 无默认／固定录制 | 96,750／101,229.5 | 97,374.5／100,479 |
| 无默认／变宽录制 | 95,646／100,292 | 97,292／98,541.5 |
| 无默认／字体样式 | 155,021／163,583 | 155,917／163,291.5 |

Runtime 三模式的 P95 中位数变化分别为：
默认 +3.09%、−1.14%、+1.03%，无默认 +0.85%、+2.18%、+0.04%。
Border 构造 P95 增加 53.12%／54.89%，每 120 次构造批次多约 14 µs，
反映基础指标检查与受检配置的代价；指标查询与绘制没有同幅度增长。
这是迁移成本，不能描述成构造性能提升。

两配置都出现过单轮尾部异常。例如无默认 resize 的迁移前／后最高批次 P95
为 99,300,875／114,755,333 ns，远高于其中位数。
本机不是独占 runner，不将中位数差异解释为普遍加速，
也不把上述结果当作单帧延迟承诺。

allocator 在每模式十轮内保持相同计数，两种 feature 配置也相同。
下表是每次执行的 101 个样本合计，不包含预热：

| 模式 | 迁移前／后分配请求次数 | 迁移前／后请求字节 |
|---|---|---|
| 稳定帧 | 373,094／392,486 | 335,261,723／340,169,818 |
| 连续 resize | 15,038,294／15,057,686 | 20,072,984,723／20,077,832,218 |
| 继承样式帧 | 13,378,460／13,397,852 | 17,796,774,387／17,801,621,882 |
| Border 构造 | 48,480／48,480 | 4,072,320／4,848,000 |
| Border 指标 | 1,111／1,111 | 127,664／135,744 |
| 固定录制 | 122,311／122,311 | 65,357,504／65,365,584 |
| 变宽录制 | 122,311／122,311 | 65,357,504／65,365,584 |
| 字体样式 | 224,523／224,422 | 52,713,011／54,654,736 |

三个 Runtime 模式均多 19,392 次请求，即每样本多 192 次，
与 64 节点初始化／首帧的固定规模一致；
后续 resize 和样式更新没有再扩大次数差量。
稳定模式的请求次数增加 5.20%，请求字节增加 1.46%。
Border 构造每组多 64 字节，指标和录制模式每次初始化／冻结多 80 字节；
后续 120 次查询或录制没有增加分配请求次数。
字体样式每样本少一次请求，但总请求字节增加 3.68%，没有据此宣称内存优化。

Runtime 的提交确认只证明准备与生命周期路径；本探针没有逐帧 GPU 时间、
输入响应时间、RSS 或浏览器运行性能。
分配请求字节也不能直接解释为复制字节或峰值内存。
共享 custom dash 的保留字节与 Clone 共享 payload 已由
`custom_dash_storage_is_charged_and_drawing_clones_share_payload` 验证；
该契约证明存储所有权，不替代全场景的复制带宽测量。

缓存回归采用外部 callback 计数。`repeated_nested_preferred_queries_use_the_session_cache_and_skip_invalid_minimum`
检查同一 session 内的重复查询不重复调用测量；
`normal_invalidation_retries_measurements_without_reusing_failed_values`
检查有效缓存复用、正常失效和失败后重试。
CPU 采样没有汇总缓存命中率，也没有把分配变化归因为某个缓存。
这些契约与批次时间分别证明复用行为和整体成本。
