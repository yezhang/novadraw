## 设计意见的最终结果

| 意见 | 最终依据 | 结果 |
|---|---|---|
| R01：阶段身份绑定 | Core 捕获引擎身份、revision、registry 身份和 key；登记、读取、回调返回及发布前校验，None／Err 分支不豁免 | 设计意见关闭 |
| R02：留存上界证明责任 | 生产者承担存储覆盖及生命周期义务，Core 检查描述、算术、身份与额度；增长须新 payload 重新准入 | 设计意见关闭 |
| R03：登记与账本生命周期 | 临时预留、fallible 存储预留、提交后 lease、失败清理及最后引用释放规则明确；淘汰不虚增可用字节 | 设计意见关闭 |
| R04：操作成本与失败 | 留存字节、会话 work／allocation 和实际字节统计分开；必要操作计划在工作发生前准入 | 设计意见关闭 |
| R05：缓存拒绝成本 | 分析查询先于新增费用判断，首次、提前拒绝、分析后拒绝与淘汰均进入性能分母 | 设计意见关闭 |
| R06：等价口径与默认启用 | B 适配、C 受控接入、D 默认配置决策分开；公开字段、资源依赖和交互行为有明确比较口径 | 设计意见关闭 |
| F01：缓存满时仍复用 | 有效分析命中不查询新增费用、不重新准入已有 backing；仅 miss 调用统一可选下界协议 | 设计意见关闭 |
| F02：多种错误同时发生 | 主错误按预算、绑定、阶段错误、Core 校验选择；伴随字段和原始 stage error／source 全部保留 | 设计意见关闭 |
| F03：context 描述一致 | context 明确提供预算、诊断和 Core 封装的只读绑定，扩展不能自行构造或改写绑定 | 设计意见关闭 |

F01 的关键区别是配置总额度为零与当前剩余额度为零：
前者选择完整入口，后者不能跳过有效模板；reflow 仍受当前会话预算约束。
费用下界未知或观测过期不能被解释为确定不足，也不能替代最终登记事务。

F02 将主错误分类与 source 追溯分开。已有 stage error 始终可沿 source 链读取，
预算和绑定等伴随事实通过结构化字段读取；错误优先级不清除粘滞失败，
任一失败均阻止本次完整回退、完整结果缓存写入和候选发布。

## 接受范围与剩余实施门禁

接受统一可选阶段入口、只去掉宽度的分析请求、typed registry 与不可变 lease、
实例留存字节计费、同会话操作预算及结构化失败合同。
保留完整布局入口，内置与外部实现共用同一模型。
局部编辑、paint-only 失效、inline 度量分离、worker 和原生 glyph 裁剪
仍不属于本次接受范围。

以下要求仍待按 A–D 切片实施验证：

- A：外部阶段与无阶段消费者、四项绑定变化、复合错误、登记事务、
  backing 去重、metadata、淘汰后 lease 和最后引用释放。
- B：Parley 存储计费接口及操作计划依据、同一字体集合、依赖补丁的来源、
  许可证、版本与 Native/Wasm 兼容。现有 Parley 0.7.0 仍不满足计费前置条件。
- C：Core 完整输出、来源、交互与资源 revision、Unicode、镜像、NoWrap、
  字体替换、真实 inline 反馈和旧 lease 的精确等价。
- D：匹配的热命中、首次、拒绝、连续 resize、淘汰和多视图数据，
  再据 C／D 证据决定默认限额及默认启用。

本次没有授权依赖补丁、确定默认字节常量或启用 Parley 缓存。
16 ms 更新和 4 ms 查询／IR 目标保持未完成，隔离 reflow 收益不替代整体验收。
接受 ADR 不自动授权全部实施切片；后续按已有执行门禁逐片推进，
状态只在 [P2 backlog](../../roadmap/p2-delta-backlog.md)维护。

交付前按技术文档清晰度与好好说话复核事实、逻辑和中文表达，
区分设计意见关闭、用户接受与待实施验证；没有另行组织独立 reviewer。
