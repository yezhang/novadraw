# 布局样例的鼠标窗口验收

类型：`manual-verification`

能力归属：平台／宿主验收。没有新增 Core 布局能力。

日期：2026-10-29

状态：macOS 代表性鼠标控件操作与窗口角拖拽通过。跨平台、系统 DPI 切换和
上游栅格对照继续保留；不是完整参数排列组合验收。

## 接续已有窗口

本轮接续[系统窗口验收](official-layout-native-window-2026-10-29.md)，使用同一
PID 6351、同一 checkout 二进制和显示器，未重新构建或重启。
原来的 System Events 坐标 click 未产生控件状态变化，本轮改用 cliclick 5.1
发送 macOS 鼠标移动、按下、拖动和释放事件。数值输入通过实际字段的双击、
键盘文本与 Return 提交。没有直接修改 Runtime、测试 fixture 或应用状态。

系统安装命令被沙箱阻断，随后下载 Homebrew 官方 arm64 Sonoma bottle，
验证 SHA-256 后在临时目录解包运行。未修改系统安装目录，没有把该工具写入
普通应用启动依赖。包指纹、截图和比较结果见
[收据](../evidence/layout-native-mouse-2026-10-29/receipt.json)。

截图仍读取实际屏幕。输入日志按发生顺序保存在同一目录的
`01-input.log` 至 `10-input.log`。
[画面总览](../evidence/layout-native-mouse-2026-10-29/contact-sheet.png)展示主要阶段；
25 张原始截图及其 SHA-256 全部列在收据中。

## 代表性操作与结果

| 场景 | 操作 | 实际观察 |
|---|---|---|
| Toolbar | Horizontal 取消／恢复，Center、End、stretch 横纵切换，Spacing 增加／归零 | 图形改变方向、位置和次轴尺寸；恢复默认配置后 Canvas 与前批默认基线相同 |
| Flow | Horizontal 取消／恢复，Major Center、Minor End、stretch、两轴 spacing 调整／恢复 | 11 个图形转为纵列并按配置排列；stretch 改变次轴尺寸，恢复后单行重现 |
| Grid | Add 四次，numColumns 改为 3，开启等宽列，选择蓝色椭圆 | 六个图形变为三列；选中轮廓加粗，属性区启用 |
| Grid | widthHint 120、heightHint 80、indent 20、两轴 span 2、两轴 grab 开启 | 椭圆占据两行两列，其余图形重排；属性数值与选择状态保持 |
| Grid | 两轴 alignment 改为 Fill；margin 15／10，spacing 12／8 | 椭圆扩展填充所占网格区域；边距、间距和控件值可见 |
| Grid | Clear All，再 Add | Canvas 清空，选择释放、属性区禁用；重新出现一个青色图形 |

Toolbar 鼠标拖拽窗口右下角从外框 1200×828 缩到 820×628，再恢复；
Flow 缩到 620×428；Grid 在 span／grab／Fill 配置下缩到 820×628。
三项均通过系统窗口查询确认尺寸，画面随窗口更新。
这是工具发送的正常鼠标事件，未由人手操作。

Grid 的临时面板在 resize 后位置向上收敛，第一次按旧坐标尝试 Clear All
没有清空图形。重新按截图中的按钮位置操作后才成功。
正式证据使用 `grid-clear-confirmed.png`，未将第一次返回成功当作清空通过。

## 恢复像素的保证范围

| 比较 | 结果 |
|---|---|
| Toolbar 控件恢复默认与前批默认 Canvas | 0 差异像素 |
| Flow 拖拽前的控件恢复画面与拖拽恢复后 | 0 差异像素 |
| Grid Fill 配置在拖拽前与恢复后 | 0 差异像素 |
| Flow 整个控件循环前后 | 18,860 像素有差异，最大单通道差值为 1 |

比较框沿用前批 Canvas 框，排除面板和窗口装饰。
Flow 的控件循环前后图形像素面积与位置一致，但部分填充的屏幕 RGB 通道
从 252 变为 251，不能记录为完全相同。
缺少渲染缓冲对照，尚不能确认差异来自系统颜色转换或渲染输出。
本轮保留原始差异，不改图、不把有差异的比较改写为零。
Flow 拖拽前后比较独立为零，证明该配置下的窗口恢复。

本次观察未发现图形残留、选择失效、清空失败后的状态损坏或窗口崩溃。
没有连续逐帧截图、帧模式统计或输入／呈现延迟测量。
既有 Label／FlowPage 和约束重测的消费者证据仍独立保留，
本轮只验收官方窗口中的图形和临时控制面板。
