## SR3-R01：可见 IR 与纹理缓存需要组合合同

优先级：P1。归属：Core 录制协议与 Vello backend 缓存协议。

原提案第 98～99 行分别安排“冷块补画与纹理像素边界”和
“原生覆盖证书与可见 IR”。栅格专题要求候选匹配完整比较绘制 payload，
生产通用层的稳定内容身份与绘制边界仍需另行评审。

引入可见裁剪后，滚动会改变命令片段，可能使当前按完整 payload 比较的缓存
失去跨滚动命中。如果直接拿当前 viewport 的 IR 填充整块，也可能漏掉块内
暂时不可见、随后会露出的内容。两项优化分别正确，尚不足以证明组合后正确且有收益。

建议在栅格专题补充稳定内容身份、块完整性与按块查询补画输入的入口，
本提案只记录组合前置条件。补画输入须覆盖块的有效输出区域及实际策略要求的
辅助覆盖；不能将本帧可见片段等同于整块内容。

复核要求：明确内容版本与本帧可见范围的绑定关系，验证
“冷块生成 → 同块内滚动 → 跨块 → 回滚”，同时核对像素、命中与失效，
确认没有因裁剪引入漏画或持续重建。

## SR3-R02：真实触控板输入需要缓存资格分母

优先级：P1。归属：platform 输入采证与 backend 缓存资格。

原提案第 398～400 行要求连续输入覆盖“上下往返、横向长行滚动、宽度缩窄与恢复”
及交错序列，但没有明确亚像素位移。现有实验固定滚轮位移为正负 40 逻辑像素，
设备亚像素平移仍走原路径。

因此热帧离屏对照的收益未必覆盖常见触控板操作；只有缓存命中样本的耗时，
不能说明真实输入整体能获得多少收益。

建议加入连续分数位移、惯性滚动与方向反转，报告缓存资格率、回退原因和
包含回退样本的整体尾延迟。亚像素支持可以后置，但先据资格率判断优先级；
不能通过取整改变滚动与命中几何。

复核要求：冻结实际输入序列与设备缩放，分别报告符合资格、命中、冷块和回退，
保留实际位移，并将整体延迟与原路径按相同序列比较。

## SR3-R03：冷块筛选与原生覆盖需要明确共同前提

优先级：P2。归属：文字墨迹 provider、backend 覆盖依据与 Core 查询通道。

原提案第 98 行将冷块补画列为“随后独立评审”，第 99 行将原生覆盖列为
“按剩余成本选择”；栅格专题要求冷块查询使用“实际 Vello 原生 glyph 覆盖依据”。

冷块筛选可以先在 backend 内部实施，Core 录制前裁剪也可以独立推进，
但两者都需要覆盖依据。当前顺序容易让读者误以为冷块筛选不依赖原生覆盖证明，
或在后端重新建立一套墨迹与覆盖规则。

建议将像素差异定位单列为可先执行的工作，并明确两层前提：
冷块筛选先完成 backend 内部覆盖依据；Core 录制前裁剪另需
Runtime／Recorder 查询通道。静态墨迹与实际 lowering policy 的合同继续由专题维护。

复核要求：说明共同覆盖依据的 owner、来源和复用边界，未知范围保留完整相关操作；
不要求先完成全部 Core 裁剪 API 才能定位像素差异，也不据 backend 筛选关闭 Core 门禁。

## SR3-R04：合并输入后的延迟归因需要定义

优先级：P2。归属：Runtime 调度与 platform 呈现采证。

原提案第 381 行要求“直接测同版本实际显示终点”，但连续 resize 合并或 worker
取消后，部分输入版本不会单独显示。第 379 行的“主线程工作 p95”也没有明确统计单位。

缺少版本关联规则时，被替代输入可能被错误计为呈现失败，或仅保留最后输入而
低估等待时间。主线程工作若按单个小区间统计，多段工作累计造成的阻塞也可能被掩盖。

建议定义被替代版本的登记方式、最终显示版本对应哪些输入，以及延迟的起算点。
主线程预算同时明确按帧累计工作还是连续阻塞区间统计，避免嵌套区间重复求和。

复核要求：在连续输入序列中追踪接收、替代、消费、提交和实际显示的版本关系，
按预先冻结的规则报告延迟；实际显示终点不可取得时仍记为 unavailable。

## SR3-R05：切片交付与生产启用需要分开判断

优先级：P2。归属：Core 切片验收与平台发布准备。

原提案第 105～106 行要求登记单一 Execute 切片，
“每批完成匹配验证后再进入下一批”，后文同时包含 CPU、像素与实际呈现目标。

这一表述没有明确每批所需的验证范围，可能被理解为必须先完成全部平台呈现采证，
才能继续 Core 开发，也可能被理解为局部 CPU 验证即可关闭生产启用门禁。

建议明确 FR-02 按 FA-G03 的实现与适用定向验证判断切片交付，
生产启用按 FA-G04；实际屏幕呈现由平台验收负责。各阶段所需的匹配成本证据
继续按冻结判据取得，不将切片完成解释为整体性能达标。

复核要求：各工作包的交付、默认启用与整体验收有明确对应门禁，
保留发布准备采证的未完成状态，并与 backlog 的恢复条件一致。
