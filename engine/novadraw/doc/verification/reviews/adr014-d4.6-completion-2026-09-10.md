## D4 完成条件

- 正常 Runtime frame 自动完成 reroute、文本派生、layout 与 presentation，不要求应用
  手工 resolve 或第二次 full redraw。
- Resource ordered delta、Ready snapshot、跨 Runtime identity、dispose、外部 text
  engine、typed component update、约束测量和 stable notification 均有公共 API 测试。
- 10,000 层默认 debug 测试线程完成 build、validate、render、hit-test、mutation、
  dispose；release 1k/10k 基准和输出等价通过。
- 递归 renderer 保留；未恢复归档迭代实现或 I 键切换。
