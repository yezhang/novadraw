# ADR-014 D4.5 递归主线性能恢复

类型：`verification`

日期：2026-09-10

状态：`complete`

## 范围

- 保留递归 renderer，不恢复归档的迭代渲染入口。
- 对齐 Draw2D `Figure.paint(Graphics)`：节点只应用 local style，继承由 Graphics
  push/pop state 承担。
- 移除 render 每节点分配 ancestor chain 并回溯解析完整 style 的 O(N²) 路径。
- validation 递归携带 ancestor visibility，避免每层重复向上扫描。
- render、hit-test、validation 每 16 层检查一次栈余量，接近 128 KiB 红区时扩展
  4 MiB 栈段，覆盖 10,000 层默认测试线程。
- 扩展 release harness，覆盖 1k/10k render、hit-test 和 validation。

Draw2D 证据：

- `Figure.paint` 只将 local background/foreground/font 写入 Graphics；
- `Graphics.pushState/restoreState/popState` 保证后代继承和兄弟隔离；
- Novadraw 的 alpha 同样作为 local override 写入当前 Graphics state。

未改变搜索结果或算法顺序。

## 语义与深度门禁

- 默认样式不产生冗余 alpha command。
- ancestor style 由 Graphics state 继承。
- child 显式 alpha 1.0 可覆盖 parent alpha，修复旧 resolved-style 路径遗漏 reset
  的边界。
- unclipped siblings 之间 Graphics state 不泄漏。
- 10,000 层默认 debug 测试线程完成 build、validate、render、hit-test、mutation
  和 dispose；release 同一测试通过。
- before/after 所有 benchmark 输出计数一致。

## 结论

A08 已关闭。递归主线恢复线性 style 传播和 validation 可见性传播，保持
self -> children -> border 顺序、child clipping 和兄弟 state 隔离。未恢复迭代
renderer，也未声明 setup/build、GPU raster 或 present 性能收益。
