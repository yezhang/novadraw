# ADR-059 B1：私有语言标签的计划准入

类型：`implementation-verification`

日期：2026-11-02。能力归属：Core（`novadraw`）文字引擎的
Harfrust 0.3.2 生产依赖。`api_semantics`：`text.flow`、`text.interaction`。
状态：本子片已实现并通过定向核验；B1 和默认启用仍未关闭。

本片接续[布局表计划准入](text-stages-b1-plan-layout-2026-11-02.md)，
补齐 BCP 47 私有标签中的 `hbot` 语言覆盖，以及计划保留语言值的容量准入。
例如 `en-x-hbsclatn-hboteng` 同时指定 OpenType script 和 language。
支持范围由标签解析路径决定，不依赖字体名或测试字体白名单。

## 从标签扫描到计划存储

普通入口与准入入口共用私有标签扫描、规范化和 script 构造内核。
通用语言表映射尚未接入准入；缺少有效 `hbot` 时，准入入口在该映射及
临时 Language 构造前返回 `Ok(None)`。普通入口仍执行已有完整映射。

| 操作 | 执行前费用 |
|---|---|
| Language 字符串访问 | 读取 byte length，再覆盖 `as_str` 的 UTF-8 验证访问 |
| BCP 47 扩展前缀 | 先检查 `x-`；每轮扩展扫描覆盖 previous／next／current 和 x 分支的重复字节访问 |
| 私有标签定位 | 对 `-hbsc` 和 `-hbot` 分别从头扫描；固定八字节块先付读取、复制和清理费用，没有首字节候选时整块跳过，其余位置先付精确比较费用 |
| 标签值 | 最多四个字节，各自在读取前准入；覆盖规范化、inline 写入、补空格的临时四字节数组、复制、重复 tag 读取及清理 |
| script 默认构造 | 最多三个四字节 tag，覆盖转换、inline 写入及清理 |
| 计划的语言值 | 长度不超过八字节时留在 SmallVec inline；超过时先 fallible 预留 Vec，再复制并转移 allocation |

语言复制直接使用已经规范化的存储字节，不再解析或重新规范化。
SmallVec 1.16.4 的 `from_vec` 在容量超过八时转移 Vec 的分配；
该分支不再额外申请一份字符串。复制和最终元素释放分别预付。
allocation 仍表示完整新增容量槽位，不按字节大小折算；
work 仍表示输入字节或元素访问，包含重复扫描。

未增加下层依赖补丁。标签搜索使用固定字宽的零字节检测和精确窗口比较，
避免把未核对的 Rust 字符串 searcher 当作已证明的费用依据。
八字节检测不漏掉候选；检测到可能匹配时仍逐字节确认，不用检测值直接返回匹配。
普通路径也共用该搜索内核，成本另作匹配比较。

## 拒绝与下一次调用

有效 `hbot` 可以出现在不同位置，前缀和语言值可以超过 inline 容量。
重复标签仍采用首个匹配；首个 `hbot` 的值无效时，不改为选择后面的标签。
复杂语言映射、脚本专用计划回调、非空 AAT、trak 和实际 shaping
仍在对应未知操作前返回未支持。

本片没有转移或修改外部 UnicodeBuffer，失败仅丢弃本次计划候选。
准入错误保留原始 source，并在拒绝点停止；不调用普通入口补做。
三个代表性标签逐点拒绝，检查完整 trace 的严格前缀、相同重试 trace、
语言 SmallVec 的 inline／spill 分支和后续普通调用输出。
这不代替实际 shaping 失败后的 buffer 恢复验收。

## 验证与成本

定向消费者覆盖结构字体、真实字体、四方向、长前缀、UTF-8 无效标签值、
重复标签、BCP 47 扩展分隔符和通用语言的提前拒绝。
私有搜索测试另外覆盖长度 0–63、每个候选插入位置、四种填充字节、
两种 needle 及首／中／尾准入点拒绝，比较显式窗口搜索结果。

补丁重放 receipt（`target/verification/text-stages-b-2026-11-02/private-language-verification.json`）
从原始归档重放九份冻结补丁，再追加本片。
五个既有源码文件改动，其他 74 个源码文件逐字节保持；
验证结束后再次核对全部 79 个生产源码文件。

| 原始／生产 Native／portable | 既有矩阵各 39,744 份和布局矩阵各 50,688 份观察一致；私有语言矩阵各 6,720 份观察一致，分别核对 SHA-256 |
| 外部 Native／portable | 各 36 项通过，包括新增两项完整输出与逐点拒绝测试 |

计划成本 receipt（`target/verification/text-stages-b-2026-11-02/private-language-cost-summary.json`）
保存三组语言、四种模式各 1,000 次有效样本，共 12,000 次。
各组预热 100 次，模式逐样本轮换。
字体使用 Inter，数据缓存、语言解析和 Shaper 配置均在计时之外。
成功计划释放在计时之外，最后点拒绝包含临时候选清理。

| 语言输入 | 普通 P95（µs） | 空回调 P95（µs） | 计数 P95（µs） | 最后点拒绝 P95（µs） |
|---|---:|---:|---:|---:|
| inline：`x-hbot1` | 4.500 | 6.625 | 7.000 | 7.084 |
| spill：`en-x-hbsclatn-hboteng` | 4.209 | 6.375 | 6.667 | 6.834 |
| 1,024 字节私有前缀 | 4.583 | 6.667 | 7.125 | 7.417 |

成功计数模式分别记录 work 5,774／6,017／15,190，
allocation 196／217／1,233，回调 1,157／1,189／1,696 次。
这些费用包含整份计划，不能解释成仅语言字符串的费用。
最后点拒绝发生在零长度 feature 复制的准入点，因此 work／allocation
与成功相同；包含候选清理并不保证拒绝更快。

原始／生产普通入口成本 receipt（`target/verification/text-stages-b-2026-11-02/private-language-ordinary-cost-summary.json`）
使用同一份普通 API 源码分别编译 Native release。
三轮轮换执行先后顺序，各组各 1,000 次、预热 100 次，共 18,000 个样本。

| 语言输入 | 原始 P95 三轮范围（µs） | 生产 P95 三轮范围（µs） |
|---|---:|---:|
| inline | 3.958–4.167 | 3.875–4.042 |
| spill | 4.000–4.083 | 3.958–4.042 |
| 1,024 字节私有前缀 | 4.209–4.334 | 4.250–4.292 |

初版逐窗口搜索曾使长前缀的生产 P95 达到 6.417–6.500 µs，
对应原始 P95 为 4.250–4.375 µs。
固定字宽跳过无候选区间后重新核验，最终采样不再出现该回退。
初版候选补丁和原始采样保留在证据目录的 `scalar-search-*` 文件中；
它们不代表最终生产源码。最终数据也不据此宣称普通路径零开销。

本机负载未控制，采样中的长尾保留。数据只描述计划构造，
不证明 Core 端到端排版、实际 shaping、GPU 或生产宽度复用性能。
成稿已分别核对事实、技术因果和中文表达，未取得独立评审结论。
