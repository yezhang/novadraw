## 修改位置与复核入口

| 意见 | 修订位置 | 本次回应 |
|---|---|---|
| R01／P1 | “Core 捕获阶段调用绑定”与失败表 | Core 捕获引擎身份、revision、registry 身份、key；登记／读取验证捕获绑定，回调返回重新读取四项，None 分支也检查 |
| R02／P1 | “生产者申报与 Core 可检查的范围” | 生产者承担上界完整性及生命周期义务；registry 只检查结构、算术、backing 身份和额度；存储增长必须新 payload 重新准入 |
| R03／P1 | “登记事务与计费账本生命周期” | 临时预留、fallible 存储预留、提交后 lease；失败清理本次预留；账本跟随最后相关 lease，淘汰不虚增剩余额度 |
| R04／P2 | “操作成本、拒绝入口与诊断” | 成本表区分字节额度、work／allocation 扣费与实际存储统计；必要 reflow 计划缺失在操作前失败 |
| R05／P2 | “正常调用和失败”及“D 的首次、拒绝和淘汰门禁” | 已知零额度／关闭／不足提前走完整入口；分析后拒绝保留成本；首次、拒绝、旧 lease 和持续淘汰全部进入正式分母 |
| R06／P2 | “实施切片与退出标准”及“C 的精确等价口径” | B 只适配，C 受控接入，D 决定默认启用和限额；字段与依赖精确比较，不要求 Arc 地址一致 |

以上位置按章节定位；评审中的原始行号保持其原基线用途。
后续独立复核应依据修订正文，不把本表当作通过结论。

## 仍需验证的反例

| 意见 | 必须补入实施验证的情形 |
|---|---|
| R01 | 四项分别变化；返回 lease／None／Err；阶段能力消失；外国 lease；变化后不得回退或发布 |
| R02 | 内部缓存未被上界覆盖；容量增长；共享引用漏报；同 backing 身份描述冲突；新 payload 准入时旧 payload 仍留存 |
| R03 | 登记中途失败；backing 部分预留；去重；最后相关引用释放；registry 销毁；淘汰后旧 lease 仍阻止新资产准入；metadata 容量释放 |
| R04 | clone／断行／导出缺计划、预算失败及回调忽略失败；操作前扣费；实际字节统计不能替代预算准入 |
| R05 | 提前拒绝只有一次完整布局；分析后拒绝的额外 analyze；零额度、超大资产、容量不足和连续淘汰的正式调用次数／失败率／尾延迟 |
| R06 | 同一资源与 provider 依赖的字段／交互差分；Unicode、inline、镜像与受约束 NoWrap；B／C 未完成 D 时不能生产默认启用 |

这些是待执行验证要求，本次没有运行或补造通过数据。
Core 前后读取绑定不等于观察任意扩展内部的中间写入；
生产者不得变更后恢复旧绑定或复用退出的代次。
Core 结构检查也不等于对第三方对象实际内存的独立证明。
