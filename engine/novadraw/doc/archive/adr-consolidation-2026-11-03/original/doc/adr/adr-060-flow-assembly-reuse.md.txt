# ADR-060：可选贡献组装复用

类型：`architecture-decision`

能力归属：Core Flow 的公开扩展合同与实例资产；Core 文字请求的共享内容构造与留存；
Core Preparation 的输入证明传递与 Runtime 发布检查。
Editor、backend、platform 无新增能力。
状态：提议，修订 1，2026-11-03；尚未接受，现行 ADR-051 保持有效。
修订回应 [FR02-DR01～DR06](../verification/reviews/adr-060-draft-review-2026-11-03.md)；
回应位置见[修订交接](../verification/reviews/adr-060-revision-1-response-2026-11-03.md)。

## 问题

完整段落缓存位于贡献组装之后。文字引擎命中仍会重新遍历 Figure、调用 contributor
和 handler，重建文本、样式与来源。只缓存 payload 不能省掉 handler 与组装；
直接缓存整页则可能漏掉扩展内部可变状态、绑定变化、边框和测量依赖。

## 拟议决策

在现有开放贡献协议上增加可选的精确复用声明，内置与外部使用相同入口。
contributor 与 handler 分别声明实例身份、版本、读取范围以及可省略回调的承诺；
无声明继续当前重读。资产归 FlowLayoutService，缓存不可变完整组装结果，
不缓存缺少几何的 FlowSnapshot，不提前缓存宽度相关 inline 测量。

只有全部参与者与读取依赖具备完整证明时，才省去 contributor／handler 执行、
组装遍历与结果重建；必要的成员／依赖扫描、声明读取、完整比较和观察回放仍保留。
首片保守采用整页命中／失效，不建设增量子树拼接。候选索引不能代替完整身份、
输入和依赖比较，不承诺消除全部 Figure 遍历。

首次捕获的声明与依赖证明由 Preparation 保留，随测量消费、准备结果和 Runtime
候选批次传递。构建或发布前版本变化使本次结果失败，不仅取消缓存安装；
普通 cache miss 与同次计算的输入变化分开。结构化错误与首次值保留到最终失败边界。

本片同时选择不可变、受检的共享文字内容资产。FlowPlan 共享后仍经 owned String／
Vec span 构造请求，会转移复制成本；因此 owned／shared 构造、内容校验、clone
和留存计费一起纳入 Core 文字请求协议迁移。外部引擎仍读取同一 StyledTextRequest，
两种构造走同一公开受检路径，不暴露 Parley 或仅内置可用的可信入口。

cache 驻留上限控制 cache 持有的资产，存活账本控制新增 backing／metadata 准入，
preparation 预算控制单次工作。缩容不使已有 lease 失效；存活留存超限时拒绝新增准入，
不强制释放旧资产。账本由服务与全部资产 lease 共同持有，最后服务销毁后仍能完成扣账。

## 替代与代价

仅复用文本 payload 改动较小，但保留 handler、遍历和来源重建，不能兑现整页收益。
仅按 scene revision 或内置 Figure 类型复用缺少扩展状态与身份依据，不采用。
首片不减少 Runtime 反馈轮次，也不同时实施宽度阶段协议。

完整组装复用需要新的扩展声明和输入检查，增加缓存留存与冷路径成本。
共享内容与证明传递增加公开 API、clone 计费和测量／准备 metadata 的迁移范围，
需验证现有 owned 调用、外部引擎和跨包消费者的兼容性。
无法证明安全的页面可能一直走原路径；必须用真实工作次数和端到端分布验证收益，
不得把协议实现或局部阶段减少视为 16 ms 更新目标通过。

## 接受后对 ADR-051 的局部效力

本提议不改变当前贡献重读要求。获接受后，仅对完整声明、绑定、依赖证明及发布
检查都满足的页面，允许用组装资产省略贡献执行；无声明或证明不足的页面仍按
ADR-051 重读。已产生的扩展、预算或输入变化错误不属于“证明不足可回退”。
完整布局、来源几何、真实 inline 测量和发布一致性要求保持；不扩大为完整测量
或整页快照复用。接受时同步 ADR-051 关联设计的对应条款并链接本局部修订。

## 接受、实施与启用

架构接受以接口职责、输入证明链、容量行为及独立消费者接入可行性评审为条件，
不要求先完成未经授权的生产实现。本轮不要求编译消费者原型，也不授权原型开发；
若后续评审需要原型，先单列其隔离范围与授权。
实施启动前冻结具体签名、容量默认值、增长前 charges、机器用例及比较／启用判据。

实施完成要求独立 crate 通过真实公开注册、错误、共享构造与生命周期验证；
生产启用另要求匹配净收益、容量和冷路径回退指标达标。
任何阶段的通过不能替代另一阶段的证据，均按设计所列门禁推进。
