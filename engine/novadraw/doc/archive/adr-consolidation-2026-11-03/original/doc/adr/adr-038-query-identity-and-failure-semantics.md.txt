# ADR-038：查询身份、合法缺失与失败传播

类型：`architecture-decision`

能力归属：Core 查询；Editor/Inspector 消费。

状态：已接受，修订 1，2026-10-16。

## 问题

以 Option 或默认值同时表达错误身份、合法缺失和测量失败，会掩盖失效引用，
让布局与坐标失败进入成功缓存。

## 决策

先验证身份，再解释值；合法缺失与领域失败分开。
任意 ID 查询与已验证视图分开，坐标、测量等领域保有自己的错误权威。
候选计算完整传播失败，不把无穷、奇异变换或非法外部结果转成零值。

## 替代与代价

不保留非权威便利 getter，也不以全局错误或 Option 擦除领域信息。
返回类型与组合错误更明确，代价是消费者必须处理原先被隐藏的失败。
