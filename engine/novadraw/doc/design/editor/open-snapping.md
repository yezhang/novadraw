# Editor 开放吸附设计

类型：`normative-design`

能力归属：Editor（`novadraw-editor`）。
策略、候选、会话与编辑反馈属于 Editor；Core 提供既有坐标与绘制依赖。
平台输入及应用模型／Guide 持久化按各自 owner 验收。
完整职责表见 [ADR-058 的分层归属](../../adr/adr-058-open-editor-snapping.md#分层归属)。

规范效力：`draft`。2026-10-29，配合
[ADR-058](../../adr/adr-058-open-editor-snapping.md)评审，尚未实施。
设计依据为需求、ADR-055 和只读 GEF 源码，未扫描 Novadraw Rust 现状。

## 所有权与协议

Viewer 持有 typed 策略注册表；每个手势持有独立 SnapSession。
注册提供关联 payload 的 identity 和实现，内置策略也以同一方式安装。
SnapSession 保存归一化操作集合、唯一锚点、目标父、输入版本、
候选索引和上次发布的受检结果；不持有模型写权限或全局缓存。

下表是协议角色，名称在接受后按公开领域路径冻结：

| 角色 | 输入／输出 |
|---|---|
| StrategyKey／Strategy | typed payload 身份、prepare／query、领域 Error |
| SnapInput | 手势身份、目标父、原始几何、可变自由度、逻辑像素阈值 |
| SnapCandidate | 轴或耦合约束、修正、稳定特征身份、优先次序与来源 |
| SnapResolution | 合成后的受检几何、采用候选、反馈描述与版本 |
| SnapSession | 生命周期与缓存；无 Command commit 权限 |

Error 保留扩展原始 source；健康但没有候选返回成功的空结果。
外部 panic 沿用 Tool／Viewer fault 合同，不折叠成未吸附。
策略输出非有限、超阈值、越权改变固定边或来自失效版本时，在发布前拒绝。
按序策略存在错误时本次候选整体失败，不静默跳过出错策略再发布其他结果。

## 手势顺序

1. ADR-055 归一化操作集合并冻结唯一锚点，排除源子树作为 targeting 对象。
2. 由未吸附指针和现行 targeting 解析目标容器；吸附不反过来改变命中目标。
3. 映射当前锚点和全部原始几何，求未经吸附的 batch surface 平移。
4. 为目标 content 域建立策略输入，查询并仲裁候选。
5. 移动将唯一修正合入 batch 平移，各 source 分别映射到目标父域。
6. 校验完整批次资格、几何与插入位置，用同一个 SnapResolution 更新反馈。
7. release 校验版本；需要时重算前述阶段，再清理反馈、构造一次 Command 和提交。

同一手势不累加上次修正，计算基线始终是未经吸附的当前几何。
targeting 与插入位置保持 ADR-055 的领域责任；有序布局可拒绝自由平移吸附，
不能把 layout 位置当作假的网格命中。拒绝后的反馈清理沿用既有受检批次协议。

resize 使用同一策略模型，但输入自由度为指定边／轴；
固定边、比例约束和最小尺寸共同定义可接受集合。
比例 resize 的候选是耦合约束，不能独立组合 x／y 导致比例漂移。
create／drop 使用当前创建锚点和模板几何，不套用已有节点的移出资格。

## 仲裁

应用显式配置策略顺序，框架不内置 Geometry／Guide／Grid 特权次序。
每策略先在允许自由度内产生候选；每轴按配置优先级、绝对修正距离、
稳定特征身份排序。先接受者占用该自由度，后续只能填充剩余自由度。
耦合候选需要一次获得其全部自由度，否则整体跳过。
完整合成后再检查几何，不发布部分成功。

精确平局通过身份与固定排序解决，负坐标与网格中点规则必须确定且测试。
网格策略的逻辑像素捕获阈值由消费者提供；若产品要求始终量化到最近网格，
使用显式模式表达，不依靠无限阈值或 NaN。
初期无隐式滞回；若真实输入显示抖动，另评审带来源身份的保持／释放规则，
不能把上次像素位置当作新的原始输入。

## 坐标与有效性

网格间隔／origin 存在目标 content 域，guide 和 geometry 特征携带各自坐标来源。
修正距统一在 surface 逻辑像素中比较，device DPI 仅由平台适配处理。
缩放、嵌套变换与滚动通过现有受检坐标 API 映射；
旋转／非均匀变换不能只用一个 zoom 标量换算阈值。
派生溢出、不可逆或无路径拒绝整个依赖该映射的候选。

SnapResolution 至少核对 model revision、Viewer 投影／坐标版本、
target identity 与策略配置版本。版本来自 owner，不新增进程全局计数器。
任何版本改变时丢弃旧结果； stationary pointer 的 auto-expose、zoom、
resize、目标删除和配置更新也必须触发重新计算。
cancel／capture lost／工具切换释放 session 与反馈，不能让下一手势复用旧 identity。

## 内置策略与反馈

Grid 使用受检正间隔、有限 origin、显式轴及启用参数。
Geometry 从当前目标域可参与的 sibling 特征建立边／中心索引；
排除操作集合及其投影后代，不将不可见或不符合应用资格的 Figure 作为候选。
Guide 消费带稳定身份的应用资源；新增、移动、删除 guide 更新配置版本。
持久 guide attachment 不由临时反馈创建，必须由应用 Command 明确提交。

反馈使用公开 Overlay 批次与候选事实生成；所有策略的反馈走相同 renderer／registry。
结束时清理采用已有事务规则，清理失败可观察且不能先执行 Command。
禁用吸附仍可显示网格；没有候选时移除旧参考线，并显示未吸附的合法预览。

## 复杂度、测量与产物

Geometry 首次扫描 N 个候选并建立轴索引，预期 O(N log N) 时间、O(N) 存储；
后续输入查询预期 O(log N + K)，K 为阈值内实际扫描候选。
以上是设计目标，实施必须以计数与原始样本验证。
索引按手势与目标版本保存，不为每个 pointer move 克隆全部模型。
反馈增删按实际采用候选执行，不因线条移动重建整个 PartTree。

测量 64／1024／10000 个候选、单选／64 项混合父批次，
分别记录索引构建、候选查询、资格、反馈和 release 完整提交。
记录 N、K、坐标查询数、分配、复制、缓存命中和 P50／P95，
避免把应用模型复制成本混入引擎候选查询。
产物以同配置独立消费者比较不消费吸附、消费内置、消费第三方三种场景；
Native／Wasm 均记录原始与传输压缩字节。
