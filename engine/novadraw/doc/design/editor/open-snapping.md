## 所有权与协议

Viewer 持有 typed 策略注册表；每个手势持有独立 SnapSession。
注册提供关联 payload 的 identity 和实现，内置策略也以同一方式安装。
SnapSession 保存归一化操作集合、唯一锚点、目标父、输入版本、
候选索引和上次发布的受检结果；不持有模型写权限或全局缓存。

下表是协议角色，名称在接受后按公开领域路径冻结：

| 角色 | 输入／输出 |
|---|---|
| StrategyKey／Strategy | typed payload 身份、prepare／query、领域 Error |
| SnapInput | 手势身份、目标父、原始几何、可变自由度、逻辑像素阈值 |
| SnapCandidate | 轴或耦合约束、修正、稳定特征身份、优先次序与来源 |
| SnapResolution | 合成后的受检几何、采用候选、反馈描述与版本 |
| SnapSession | 生命周期与缓存；无 Command commit 权限 |

公开路径拟定为 `novadraw_editor::snap`，不增加根目录平铺重导出。
`StrategyKey<S>` 表示策略协议与关联 payload 的类型身份；
同类策略可以有多个配置实例，各实例持有 Viewer 所属的 `StrategyId`。
字符串只用于诊断，不能选择算法、标识 Guide 或决定候选相等。
注册、替换、注销、排序和显式配置更新均返回受检结果；
foreign／retired 身份在调用扩展前拒绝，失败不发布新配置。

策略协议使用关联 payload 与 prepared 查询状态。注册表保存 erased 调用桥接，
不把 `Any` 字典作为公开主协议，不要求 payload／Error／prepared 状态
额外实现 Clone／Send／Sync。Grid、Geometry、Guide 以普通策略实例注册。
查询上下文只读，prepared 状态只保存 owned 配置、特征和索引，
不保存 Runtime／Viewer 的可写借用。配置变化必须经过受控更新或所属模型的 revision；
外部策略偷偷改变未声明依赖的捕获状态不属于框架可检测的行为。

### 受检输入与特征

SnapInput 由 Editor 从已验证的操作、目标与当前场景构造；
第三方策略能贡献候选，不能构造“已检查”的输入或最终 receipt。
输入至少包含：

- 手势、Viewer、源集合及唯一锚点身份；当前目标 content pane；
- 未吸附的原始角点、当前指针和 source／target 完整仿射映射；
- 操作声明的自由度、固定控制点、最小尺寸、比例与布局允许的位置约束；
- 受控策略绑定授权的候选准入协议及参数，以及策略顺序与配置版本。

Editor 新增受检特征查询入口：从 Core 的 `figure_bounds`、
`is_effectively_visible` 与完整坐标映射提取候选，保留错误。
合法不参与返回成功的空结果；foreign／retired、数值失败或路径失败返回错误。
不能借 `part_bounds_in_surface` 的 Option 把失败解释成没有可吸附对象。
默认矩形特征与第三方提供的操作边界共用 typed provider／payload／registry；
不为内置 Figure 增加专用 match。候选特征带来源身份、几何和依赖版本。
Geometry 的候选来自目标域 sibling，排除操作集合及其投影后代；
采用 committed 几何，不把动画 presentation envelope 当作可提交模型约束。

Error 保留扩展原始 source；健康但没有候选返回成功的空结果。
外部 panic 沿用 Tool／Viewer fault 合同，不折叠成未吸附。
策略输出非有限、违反其获授权准入规则、越权改变固定边或来自失效版本时，
在发布前拒绝。候选准入不以策略名称判断，规则见下文。
按序策略存在错误时本次候选整体失败，不静默跳过出错策略再发布其他结果。

## 手势顺序

1. ADR-055 归一化操作集合并冻结唯一锚点，排除源子树作为 targeting 对象。
2. 由未吸附指针和现行 targeting 解析目标容器；吸附不反过来改变命中目标。
3. 映射当前锚点和全部原始几何，求未经吸附的 batch surface 平移。
4. 为目标 content 域建立策略输入，查询并仲裁候选。
5. 移动将唯一修正合入 batch 平移，各 source 分别映射到目标父域。
6. 校验完整批次资格、几何与插入位置，用同一个 SnapResolution 更新反馈。
7. release 使用本次最新 logical surface 位置重新同步并建立输入，
   重新执行 E03 的目标、资格和完整计划校验；最终检查、清理成功后，
   构造一次 Command 和提交。流程不包含额外失效重试。

同一手势不累加上次修正，计算基线始终是未经吸附的当前几何。
targeting 与插入位置保持 ADR-055 的领域责任；有序布局可拒绝自由平移吸附，
不能把 layout 位置当作假的网格命中。目标资格合法拒绝后可以沿用 ADR-055
的祖先 targeting，但必须为新目标重新建立输入和候选；旧目标的结果不能复用。
一旦选定目标并开始候选求解，不因某条参考线改变 targeting。
拒绝后的反馈清理沿用既有受检批次协议。

resize 使用同一策略模型，但输入自由度为指定边／轴；
固定边、比例约束和最小尺寸共同定义可接受集合。
比例 resize 的候选是耦合约束，不能独立组合 x／y 导致比例漂移。
create／drop 使用当前创建锚点和模板几何，不套用已有节点的移出资格。

实施入口为 `snap::ResizeProtocol`、`ResizePlan` 和 `ResizeTool`。
应用声明源矩形、几何域到原父域的映射、最小尺寸及可选比例；
Editor 捕获源身份、原父关系、模型 revision 和 policy generation。
当前切片处理单个源的八方向 resize。普通边拖拽只开放该边的自由度，
角拖拽开放两边；比例角拖拽使用一个宽度自由度，联动高度并保持对角固定。
比例必须与非零基线尺寸一致。比例侧边拖拽无法同时保持正交固定边，
因此结构化拒绝；居中 resize 和多源 resize 不属于当前切片。

最小尺寸使用普通注册的 `ResizeLimits` 求值器；
消费者也可提供相同 `ResizeLimitsPayload` 的第三方求值器，在保留最小尺寸约束后
增加业务限制。两者使用同一个 RuleBinding、预算、版本和错误通道。
额外布局约束由原父 policy 的 `ResizeLayoutConstraints` 请求返回。
父 policy 的实际 ResizePlan 必须声明 Command 消费的矩形；
Editor 从真实四角恢复自由度，检查固定边、比例、全部布局与采用事实。
实际计划改变允许边但破坏命中时也拒绝，不从原输入重新求解。
Handle 和程序化启动共用此流程，release 使用最新位置；清理成功后只构造一次命令。

### 布局与最终计划

布局允许的位置集合由目标 policy 的只读约束贡献进入 SnapInput，
与固定边、比例、最小尺寸一起限制候选；这些贡献使用开放协议，
框架不读取应用私有布局字段。约束未知时不能推断任意平移都合法，
由 E03 的最终计划返回值完成受检确认。

一次流程的顺序为：获取目标约束 → 生成和仲裁吸附候选 →
E03 生成完整计划及其实际几何 → 对实际几何验证布局、全部采用约束和输入依赖 →
发布绑定该计划实际几何的 resolution／反馈，或拒绝。
布局允许的改写若仍满足全部吸附事实，则反馈和 receipt 使用该实际几何；
如果改写使任一事实不成立，本次流程拒绝，移除旧命中反馈。
不把布局最终位置标为已经失效的吸附命中，不重新求解相同冲突，
不静默删除较早命中后改为未吸附提交。用户可通过显式配置禁用不适合该布局的策略。
合法有序布局不接受自由平移时，可在查询阶段返回无候选，区别于采用后校验失败。

## 仲裁

应用显式配置策略顺序，框架不内置 Geometry／Guide／Grid 特权次序。
每策略先在允许自由度内产生候选；每自由度按配置优先级、surface 修正距离、
稳定特征身份排序。候选包含写入集 W、约束依赖集 D、修正和对齐约束；
W 必须是当前允许自由度的子集，D 列出判断该事实需要读取的全部自由度。
先接受者占用 W 并保护 D；较晚候选不能写入已占用或已保护的自由度。
耦合候选需要一次取得全部相关自由度，否则整体跳过。

对齐约束使用 typed identity／payload／registry 的可求值协议，
在只读最终几何上下文中返回 `Result<bool, Error>`，不要求线程或 Clone 约束。
内置线性约束以 `Σ aⱼ qⱼ = b` 表示，非零系数对应依赖集；
例如旋转后的参考线可能同时依赖两个平移分量，不能声明成只依赖 x。
外部约束声明完整依赖并提供同一协议的求值器；声明不能替代实际求值。
数值容差在受检输入中固定，几何容差不扩大捕获半径。
外部隐藏依赖违背扩展合同，框架仍在每次暂定合成与最终计划上重验采用事实，
不能仅因自由度声明不冲突就发布命中。

按固定顺序尝试每个候选，先验证其自身准入与事实，再将修正加入暂定几何，
验证布局、几何和此前全部接受的对齐约束。
候选自身宣称的对齐事实不成立属于非法输出，拒绝整次求解；
自身有效但与较早事实冲突才属于合法跳过。
合法候选导致冲突或事实不成立时，跳过该较晚候选，保留较早候选与原几何；
非法字段、错误或 panic 进入整体失败通道。不会回溯撤销高优先级命中来满足低优先级。
最终 E03 计划几何再验证全部采用事实；此处失败拒绝整次流程，
反馈集合只能从最后通过的采用事实生成，不发布部分成功。

精确平局通过身份与固定排序解决，负坐标与网格中点规则必须确定且测试。
固定顺序为策略实例配置顺序、修正距离、provider 配置顺序、
特征在该 provider 内的稳定排序键、候选在该特征内的稳定次序。
类型身份只用于协议分派，不使用 TypeId 的运行时顺序决定平局。
同一候选身份而几何不同属于无效策略输出，不能依赖
HashMap 遍历或指针地址决胜。排序数值必须有限，不使用 NaN 排序兜底。
Grid 最近格点的精确中点采用 ties-to-even，按目标域
`(value - origin) / spacing` 求格点序号，派生溢出拒绝，不修改输入隐藏失败。
### 公共候选准入

候选准入本身使用 typed identity、payload trait 与 registry，
由受控策略绑定授权可用规则及配置。策略不能自行把越界候选升级为免检模式，
仲裁器不按 Grid／Geometry／Guide 类型放行。

| 公共规则 | 发布前检查 | 内置与外部使用 |
|---|---|---|
| 阈值捕获 | 候选单独作用的 surface 捕获距离不超过有限非负半径 | 默认 Geometry／Guide、捕获模式 Grid，以及第三方策略 |
| 精确投影 | 检验冻结的原始输入到候选目标的投影关系；不受捕获半径限制 | 始终量化 Grid 的最近格点关系，以及第三方确定性投影策略 |

精确投影规则提供 owned 参数和只读关系求值，原始输入不可换成上次吸附结果。
Grid 的该关系检查目标确为按 ties-to-even 选取的最近格点；
第三方规则也通过相同准入分派与错误路径求值。
格距 100、捕获半径 8、原始坐标 40 的例子中，
阈值捕获模式不能接受到 0 的修正，精确投影模式可以；
两种模式都要检查有限值、固定边、自由度、布局、版本、候选预算和最终对齐事实。
不使用无限半径、NaN 或内置专用 hook 表示始终量化。

初期无隐式滞回；若真实输入显示抖动，另评审带来源身份的保持／释放规则，
不能把上次像素位置当作新的原始输入。

“没有候选”“合法约束冲突而跳过候选”和“策略失败”是不同结果。
正常查询的有限候选由仲裁决定采用或跳过；越权／非有限／伪造来源的输出、
prepare／query 的 Error 和 panic 不允许静默跳过。
全部候选检查通过后才发布一次完整 resolution，没有部分成功的 receipt。

来源数、索引特征数、单次候选数和反馈贡献数由显式有限预算控制，
集中在 SnapSession 的受检配置中，不在内置策略里另藏上限。
候选通过有界 sink 贡献，超过预算整次拒绝，不能截断后发布成功。
预算限制框架接受的资源，不承诺中止任意外部回调或回收其自建分配；
外部 prepare／query 的时间与分配单独测量，panic 仍按既有 owner fault 处理。

## 坐标与有效性

网格间隔／origin 存在目标 content 域，guide 和 geometry 特征携带各自坐标来源。
修正距统一在 surface 逻辑像素中比较，device DPI 仅由平台适配处理。
缩放、嵌套变换与滚动通过现有受检坐标 API 映射；
旋转／非均匀变换不能只用一个 zoom 标量换算阈值。
自由度由操作定义：移动的批次平移与 resize 的可变边不共用虚假的 surface 轴。
每个候选记录所占用的自由度及由完整映射得到的控制点修正；
阈值捕获的距离为该候选单独作用时，被改变控制点的最大 surface 位移；
精确投影记录同一距离用于排序与诊断，但按其投影关系准入。
分别在阈值内的独立候选可以合成对角修正，合成向量长度不再冒充单轴捕获距离。
比例／斜向约束需要耦合修正时一次取得全部相关自由度，再检查固定边和最小尺寸。
旋转矩形保留四角和真实边，禁止由 AABB 推导其模型宽高；
若目标 layout 无法表达最终几何，沿用 ADR-055 的几何拒绝，不能近似后提交。
派生溢出、不可逆或无路径拒绝整个依赖该映射的候选。

SnapResolution 保存 Editor 构造的输入 receipt：源模型 revision、已应用的
projection revision、源／目标身份、source／target content 映射、
viewport origin／scale／client bounds、权限代际及策略绑定／配置版本。
不假定 Core 有新的全局“坐标 revision”；采用既有 owner 版本和实际映射值校验。
候选依赖的 sibling 几何／可见性通过受控特征版本或当前快照检查；
不能只比较源和目标映射就宣称其他候选未变化。

### prepare／query 依赖表

prepare 构建候选特征与索引；query 使用已验证 prepared 状态和本次输入计算候选。
下表规定最低失效规则，不由实现者自行猜测。变化通知用于安排刷新，
每次 query 和 release 前仍须检查依赖快照，不能仅因没有收到通知就认定有效。
多个变化同时发生时，优先取消来源已失效的手势，再决定 prepare／query。

| 依赖／owner | 变化入口与校验依据 | 缓存动作 |
|---|---|---|
| 源模型、源／目标身份、权限／Editor | ADR-055 模型通知、身份生命周期和 policy generation；比较冻结 revision、身份、代际 | 来源或权限失效则取消；合法换目标则新 prepare |
| 策略实例配置／Editor | 注册、替换、注销和受控配置更新；绑定身份、配置代际和完整配置快照 | 配置变化重新 prepare；注销／foreign 不复用旧 prepared |
| 仅策略仲裁顺序／Editor | 受控排序更新及绑定集合比较 | 集合、实例配置和声明的 prepared 依赖未变时仅 query／仲裁；否则 prepare |
| provider 绑定／Editor | provider 安装、替换、注销；绑定身份、代际和贡献协议 | 对受影响的全部特征重新 prepare |
| sibling 与 provider 候选集合／Editor、应用 | 模型／投影通知与受控资源更新；比较目标的完整有序 sibling 身份集合及 provider 集合快照 | 模型 revision 变化取消；其他合法集合增删重新 prepare，不能只验证旧成员版本 |
| 特征几何／Core、provider | bounds、component／provider 更新；比较完整角点、来源身份和 provider 数据快照 | 来源仍有效时重新 prepare，相关操作来源变化则按 E03 取消 |
| 有效可见性／Core、provider | 自身／祖先可见性或参与资格更新；比较当前有效可见性和资格快照 | 来源仍有效时重新 prepare，隐藏／恢复均改变候选集合 |
| 特征相对目标的映射／Core、Editor | 父链、content transform 和目标变化；比较完整 `target⁻¹ · feature` 映射 | 相对映射变化重新 prepare；奇异／溢出拒绝 |
| viewport 与共同 surface 映射／Editor、平台 | zoom／scroll／resize／auto-expose；比较 origin、scale、client bounds 与完整映射 | 目标域特征及相对映射未变，且 prepared 未依赖已改变的 surface 数据时仅 query；否则 prepare |
| 本次指针、操作修正与释放位置／Editor、平台 | 实际输入事件；比较最新位置、原始操作几何、自由度及准入参数 | prepared 依赖未变时仅 query；release 始终重建输入并执行完整 E03 计划校验 |
| 布局约束／目标 policy | 只读约束贡献及其完整依赖快照；受控 policy generation | 权限／policy 代际变化取消；只在来源仍有效且约束快照相同时复用 prepared |

prepared 的依赖声明也走 typed 协议，必须覆盖其实际读取的输入；
不声明可复用依赖的第三方 prepared 状态，在输入变化时保守重新 prepare。
不能要求外部配置实现额外的 Clone／Send／Sync 来验证快照。
快照由 owner 的代际、owned 特征数据或只读受检比较入口提供；
对不可比较且没有可靠版本的外部数据，不宣称缓存命中。

候选集合必须覆盖新增成员。初期可以每次校验完整 sibling／provider 集合和
特征快照，其 O(N) 工作量计入来源验证；如采用 Editor 维护的集合代际，
必须证明新增、删除、隐藏、恢复、provider 替换和祖先映射变化均能更新它。
不能只比较旧索引已有成员的版本，也不新增未经核验的 Core 全局 revision。
模型新增 sibling 的用例首先验证旧 E03 手势取消，新手势不得使用旧索引；
非模型 provider 候选新增则验证同一有效手势重新 prepare。

| 变化 | 原手势处理 |
|---|---|
| E03 来源的模型 revision、源身份、源权限代际变化 | 取消；不取新基线自动续接 |
| 当前 target 合法改变 | 重新 targeting、资格和策略准备，不复用旧目标 receipt |
| target 被删除或旧权限代际失效 | 沿用 E03 的取消／拒绝规则 |
| zoom／scroll／resize／auto-expose 改变坐标 | 来源仍有效时重建输入、必要索引和反馈 |
| 独立吸附配置或非模型 Guide 快照变化 | 来源仍有效时使旧 receipt 失效并重新查询 |
| prepare／query 返回前输入再次变化 | 本次求解拒绝；无自动重试循环 |

stationary pointer 的 auto-expose、zoom、resize 和配置变化也须重新进入该检查，
不要求伪造 pointer move。Guide 如果属于业务模型，其修改按模型 revision 取消；
独立显示资源则通过受控配置更新。两者不能由策略自行混用。

### 释放求解与拒绝终点

每次 release 恰好进入一次完整流程：读取本次最新位置 →
同步并验证冻结来源 → targeting 与新 SnapInput →
依赖检查、必要 prepare、query／仲裁 →
E03 最新资格与完整计划 → 最终事实校验 → 清理 → 构造并提交 Command。
没有“先用 move 结果提交，失败再重试”的路径，也没有额外失效重试。
最多一次指每个 release 的这次必要流程，不是 move 结果之外可额外循环一次。

完整 SnapInput 的位置、原始几何、自由度、准入规则和依赖快照全部相同，
且缓存的完整候选／采用事实可重验时，才允许复用吸附计算；
E03 的释放资格与完整计划仍重新校验，不能复用旧 checked plan。
最后一次 move 在 A、release 在 B，即使版本相同，也必须按 B 求解。
流程内输入再次变化、布局最终几何破坏采用事实，或清理后、构造 Command 前
仍失效时，拒绝本次 release 并按既有规则清理；不自动从新基线重启流程。
清理自身失败仍返回可观察的清理错误，不宣称反馈已经移除。
下一次有效输入可继续既有规则允许的手势，已取消的手势必须重新开始。
即使映射值改回原值，也必须检查当前来源、权限和配置身份；
不承诺复原已经取消的手势。
cancel／capture lost／工具切换释放 session 与反馈，不能让下一手势复用旧 identity。

## 内置策略与反馈

Grid 使用受检正间隔、有限 origin、显式轴及启用参数。
Geometry 从当前目标域可参与的 sibling 特征建立边／中心索引；
排除操作集合及其投影后代，不将不可见或不符合应用资格的 Figure 作为候选。
Guide 消费带稳定身份的应用资源；新增、移动、删除 guide 更新配置版本。
持久 guide attachment 不由临时反馈创建，必须由应用 Command 明确提交。

GEF `SnapToGuides` 对多选返回未处理方向。Novadraw 允许多选的唯一锚点
贡献 Guide 候选，全批次只获得同一 surface 平移，作为单独验证的扩展语义。
receipt 保存锚点、Guide、对齐特征与修正事实；应用 Command 决定是否只关联锚点、
关联业务组或仅移动，临时参考线不能替应用选择持久化范围。
本片不包含 Ruler 控件或 Guide 创建工具。

反馈使用公开 Overlay 批次与候选事实生成；所有策略的反馈走相同 renderer／registry。
结束时清理采用已有事务规则，清理失败可观察且不能先执行 Command。
禁用吸附仍可显示网格；没有候选时移除旧参考线，并显示未吸附的合法预览。

## 复杂度、测量与产物

Geometry 首次扫描 N 个候选并建立轴索引，预期 O(N log N) 时间、O(N) 存储；
后续输入查询预期 O(log N + K)，K 为阈值内实际扫描候选。
以上是设计目标，实施必须以计数与原始样本验证。
此复杂度只针对共享坐标域中的可排序轴特征；一般外部耦合特征的算法和成本单列，
不能套用该公式。旋转域按真实特征坐标建立索引，阈值邻域由完整映射推导；
不能为追求复杂度把真实边改成 AABB。
索引按手势与目标依赖保存，不为每个 pointer move 克隆全部模型。
按依赖表决定重新 prepare 或仅 query；来源验证需要的树遍历、
特征快照检查和 E03 的完整 projection 成本分别计数，不包含在快速查询承诺内。
反馈增删按实际采用候选执行，不因线条移动重建整个 PartTree。

测量 64／1024／10000 个候选、单选／64 项混合父批次，
分别记录索引构建、候选查询、资格、反馈和 release 完整提交。
记录 N、K、坐标查询数、分配、复制、缓存命中和 P50／P95，
避免把应用模型复制成本混入引擎候选查询。
未消费吸附、消费内置和消费第三方三种消费者检查公开领域 API 与依赖边界。
体积比较只在用户明确要求时执行，不测 Native／Wasm 原始或压缩字节作为默认门禁。
