# 富文本正文反馈与段落布局复用

类型：`normative-design`

能力归属：Editor 持有反馈节点和候选发布事务；richtext 持有不可变段落、布局资产
和高度索引；应用 Plan 证明正文贡献等价。Core 的记录、damage 和后端边界不变。

状态：2026-11-06 用户授权的两个优先项已实施，定向验证通过；
点击呈现成本仍开放，见[实施记录](../../verification/reviews/richtext-incremental-feedback-2026-11-06.md)。
前置协议：[统一会话与专用控制器](specialized-edit-controller.md)。

选区改变仍替换全文反馈，使排版缓存命中后继续支付正文记录与编码成本。
文档改变则丢弃全文缓存，使一次段内插入重新排版所有段落。
本切片分别缩小反馈节点替换与文字排版的范围。

## 正文反馈复用

`EditSessionPlan::reuse_feedback(previous, candidate, model)` 默认返回 false。
返回 true 表示整组领域反馈的内容、样式、布局和交互目标仍等价；
selection、caret 和 preedit 的 Viewer 装饰不属于领域正文贡献。
Plan 只检查控制器和模型，不接触 Runtime。plain 适配也通过同一协议声明复用。

Viewer 先克隆控制器并应用输入，再检查复用证明。在复用路径中，geometry 只读
已发布正文；不能修改旧节点的 bounds 或 component。成功生成并验证新几何、
发布装饰后，Viewer 发布候选控制器。无选区和 preedit 时保留已有 caret 节点，
由 Viewer 在发布阶段设置新 bounds 和显隐；几何回调仍只读正文。其他装饰组合
先挂载新装饰再删除旧装饰，因此可能仍触发 Core 的保守整帧修复。
正文 FigureId 和准备资产
保持不变。失败时清理新装饰并保留旧控制器及正文。未知状态与 panic 沿用 fault
边界。布局或变换同步仍使用完整候选反馈路径，避免旧几何被候选修改。
caret bounds 写入后若显隐设置失败，恢复旧 bounds；恢复失败走未知状态 fault。

Plan 必须将文档版本、布局宽度、内容样式与领域反馈依赖纳入证明。样例只在
richtext 文档版本相同且反馈布局来自当前模型时声明等价。正文变更、IME 改字
和 resize 重建正文；光标移动和 composition 装饰变化可复用。

## 段落布局复用

缓存仍只保留两个完整快照。文档候选 fork 有界缓存条目，共享不可变旧快照，
不共享后续淘汰操作；拒绝的候选不能驱逐活动正文。

缓存查找除文档版本外，还检查引擎身份、字体 generation、约束宽度和布局方向。
全文命中直接返回原快照。全文未命中时，仅从排版环境完全匹配的旧快照寻找
`Arc::ptr_eq` 的不可变段落。段落 Arc 包含文字、span、默认样式、方向、对齐和
段后间距；仅 ParagraphId 相同不足以证明等价。

新快照共享未变段落的 `Arc<StyledTextLayout>`，只对变化段落构造 request 并调用
排版引擎。同一段落顺序和数量下，以旧高度索引为基础，只更新变化高度的树路径；
结构改变时重建索引。快照元数据扫描仍为 O(段落数)，排版成本随变化段落的文字量
变化。宽度、字体 generation、引擎身份或方向变化不能复用旧段落布局。

每次新快照都有新布局身份，位置必须重新准入；旧快照的几何仍有效。准备预算覆盖
元数据扫描、分配与变化段落排版；失败不发布部分缓存。绘制继续提交全部段落，
不根据逻辑高度推断字形墨迹覆盖，也不展开段落 Figure 或 EditPart。

## 验证

检查正文节点身份保持、选区新几何、拒绝和 panic 清理、plain 回归及独立消费者。
排版引擎计数验证段内插入、替换、删除和 composition 回滚只排变化段落；
对照完整重排的尺寸、下游 caret、selection 和旧位置失效。
检查不同宽度、字体、引擎和无 cache identity 的强制重排及失败预算。

使用同一依赖和配置采样 mixed/large 点击及编辑。分别记录输入、帧准备、后端提交
和 GPU 完成；GPU 离屏数据不作为屏幕 input-to-photon 验收。正文节点复用和增量
排版通过，不代表可见段落绘制或长文黑帧已完成。
