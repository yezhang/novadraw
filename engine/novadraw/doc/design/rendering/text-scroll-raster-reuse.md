# 纯滚动的文字栅格复用实验

类型：`proposal`

能力归属：Core 保持现有布局、绘制与提交协议；Vello backend 拥有栅格缓存、
GPU 纹理与资源生命周期；TextFlowLarge 宿主提供开关和对照回放。Editor 不在范围。

日期：2026-11-04。用户“按这个思路尝试下”授权隔离实验；本实验默认关闭，
不代表接受新的 Core 缓存协议或生产启用。

## 目标与不变量

纯滚动不改变文字内容、字体、排版和样式时，复用内容坐标中的栅格块，
只合成当前可见块。新露出的块首次绘制；回滚到驻留块时不再编码字形和栅格化。
布局稳定化、命中、通知、damage、资源校验及 Runtime 提交确认继续执行。

内容变更、字体版本、样式、绘制顺序、缩放和设备／session 变化不得错误命中。
缓存容量有限，淘汰须解除 Vello 纹理注册；失败不能出版缺失块或跳过确认。
动态内容仍保持命令顺序；若与文字混在同一缓存范围中，其变化使整个范围失效。

## 首个实验范围

后端从受检 command stream 提取首个至最后一个 glyph draw 之间的连续绘制范围。
仅接纳纯平移、相同矩形 clip、普通抗锯齿文字与矩形填充；
clip 与 surface 相交后的有效可见边界必须按设备像素对齐。
其他图元、路径 clip、缩放／旋转、设备亚像素平移、可见的亚像素 clip
和不一致 clip 均走原路径；屏幕外的分数边界不影响资格。
状态命令继续执行；替换范围中的 draw 保持原始顺序，合成发生在首个 draw 的位置。
不按 Figure 类型识别 TextFlow，不设内置 Figure 特权。

完整绘制 payload、相对变换、横向栅格原点、DPI 与资源 session 用作等价依据；
候选匹配必须完整比较，不以散列或正文长度代替相等。
当前 clip 在合成时执行，纵向滚动平移独立于内容身份；横向移动使缓存失效。
缓存只覆盖当前可见的纵向块，GPU 驻留与全文高度无关。
块边缘按设备像素对齐，透明纹理的 alpha 格式与 Vello 输出一致。

本轮块高为 512 设备像素，原始 GPU 纹理驻留预算为 16 MiB，录制上限为
16,384 条命令；不满足预算走原路径。该预算不包含 Vello 图像 atlas、
临时 GPU 分配、在途 GPU 工作仍保留的淘汰纹理或完整命令引用保活的 CPU backing，
不能当作全部内存上限。

该范围用于验证“复用文字纹理”本身的收益，仍有逐帧完整命令录制、比较成本，
不声称消除 Flow 组装。生产通用层缓存需要稳定内容身份、绘制边界和完整失效证明，
另行评审；不凭实验新增公开 Core 协议。

## 分层推进

| 阶段 | owner／变更 | 验证 |
|---|---|---|
| 栅格实验 | backend 私有提取、有限纹理块与显式启用；宿主回放开关 | 正向滚动／回滚、冷块与热块、像素对照、失效／不合格回退 |
| 排版复用 | Core 依既有 FR-02 完整声明与依赖证明推进 | contributor／handler／border／inline、预算及最后发布前变化；不以宽度相同跳过 |
| 生产层协议 | Core 提供稳定绘制身份，backend 管理策略 | 外部消费者、组合顺序、缩放／DPI、容量、设备恢复及平台证据 |

FR-02 的既有未接受状态和验收矩阵保持，见
[贡献组装复用](../architecture/flow-assembly-reuse.md)。
后端策略依据 [UpdateManager](update-manager.md) 的 damage 等价约束。

## 成本与验收

对同一 release、字体、窗口和固定滚动序列，在同一实验构建下关闭／开启缓存。
分别统计输入＋帧的墙钟成本、Flow build、Vello 调用、栅格冷块与热块。
细粒度 SDK 对照必须同配置，不能把观测扰动算作优化收益；
无采集路径另测宿主操作与帧耗时。没有 GPU timestamp 时不把 Vello 调用称为 GPU 时间。

像素对照与成本采样分开运行，读回不进入性能结果。
还需覆盖追加、resize、重置、容量淘汰、不同 clip／图元回退及失败恢复。
实验结果进入 verification，真实窗口持续滚动和系统呈现仍需单独验收。

## 冷块补画的候选改进

2026-11-04 的[匹配对照](../../verification/reviews/textflow-scroll-raster-experiment-2026-11-04.md)
支持驻留热块复用，但长距离像素回放的 35 次滚动中有 24 帧需要新增一块。
冷块目前仍处理完整文字范围；仅减少最终合成 Scene 的 glyph 不能证明冷块成本下降。
以下为待评审建议，不扩大已授权实验或默认启用范围。

### 共同覆盖依据与两层接入

静态墨迹由文字墨迹 provider 按字体实例与布局版本持有；
实际 lowering、AA、数值域和辅助覆盖依据由 backend policy 持有。
定义与未知回退统一引用
[原生覆盖专题](../architecture/long-text-native-coverage-boundary.md)，
不在冷块路径复制另一套墨迹或覆盖规则。
backend 冷块筛选须先具备本设备和本策略的覆盖依据；Core 录制前裁剪则还需
Runtime 冻结绑定、Recorder 查询和 backend 提交核验。
前者可以独立交付，不能据此关闭后者门禁；像素差异定位无需等待两层 API 全部实现。

先定位现有像素差异，再限制冷块的文字输入。43 帧对照有 409 个像素的任一通道
差异超过 1，最大差异为 32；不能宣称位级相等或自行接受新容差。
定位时分别比较直接绘制、单块纹理合成和相邻块合成，记录差异坐标是否落在
块边界、glyph 墨迹边缘或有效 clip 边缘。固定字体、AA、颜色空间、纹理 alpha
与设备原点，核对平移前后直接路径的误差；未确认原因前不把差异归为块缝。

冷块候选查询使用该块的设备输出区域与实际 Vello 原生 glyph 覆盖依据，
保留所有与其相交的完整绘制操作及顺序。Core 的录制前裁剪由
[原生覆盖专题](../architecture/long-text-native-coverage-boundary.md)负责；
backend 内部冷块筛选只减少后端补画，不声称省掉 Core 全文 IR。
不能用 line box、advance、source offset 或固定边缘像素代替覆盖证明。
描边、负 bearing、装饰、复杂 clip 或覆盖未知时保留完整相关操作。

只有静态索引随内容版本复用、每次查询不重扫全文时，筛选才有减少冷块成本的可能。
若需要块外辅助覆盖，扩张量必须由实际策略推导；合成只采样块的有效区域，
相邻块不重复混合同一像素。索引构建、查询、未知退化和块间重复输入均单独计费。
失败块不登记完成，错误沿后端恢复协议返回，不能呈现缺失块或用旧内容冒充新版本。

预取在冷块资格与正确性成立后单独评估。可见缺失块优先，
相邻预取受显式工作与驻留预算限制；新滚动或内容版本出现后丢弃过时请求。
不在热帧同步无界补画，不把未来 worker 或 GPU 异步调度当作当前能力。
收益需覆盖方向反转、淘汰、追加、resize、DPI 和 session 变化；
同时观察预取是否挤出即将使用的驻留块、提高尾延迟或增加在途显存。

进入生产启用评审前，须分别取得像素差异裁决、持续滚动冷块成本、
真实窗口净延迟与完整内存口径。热块的既有有限采样不能代替这些证据。

## 可见 IR 与纹理缓存的组合条件

现有实验以完整 command payload 比较内容。Core 可见裁剪会改变每帧命令片段，
因此不能沿用该片段作为跨滚动缓存的完整内容身份；两项优化分别通过不代表组合通过。
以下为候选合同，具体公开签名与注册方式在实施前评审，不声称已提供按块查询 API。

Core 提供同次受检发布的不可变内容资产，绑定 owner、布局／内容版本、完整绘制
顺序和资源依赖；稳定身份通过 typed identity、payload trait 与实例 registry
提供，外部消费者与内置实现共用。viewport 可见范围与纵向位置作为本帧投影，
不单独改变稳定内容身份；实际内容、字体、样式或绘制顺序变化须使身份失效。
横向栅格原点、DPI、backend session、policy、AA 和影响块生成的 clip／效果
另入后端栅格键。不能只用 Figure ID、正文长度或散列证明完整内容相等。

按块查询读取该不可变资产，以内容坐标中的块有效区域为目标，使用共同覆盖依据
保留所有可能贡献像素的有序操作及所需状态；辅助区域由实际 policy 推导。
查询不受本帧 viewport 可见片段限制：视口只负责挑选及合成块，块生成须覆盖
其整个有效区域，包括当前不可见、同块内滚动后将露出的内容。
状态不足、覆盖未知或资产不能提供整块输入时，不登记完整块；走原完整路径。

backend 只在整块渲染成功、资产／session／policy 绑定检查有效后登记完成；
缓存记录持有资产 lease、块区域与生成键，局部预览不得标为完整块。
内容变更或设备恢复后旧完成状态失效，错误按原恢复协议传播。
记录前可见 IR 与整块查询共用同一已发布内容和绘制顺序，不能分别捕获不同版本。
合成保持原范围的顺序，不越过动态 overlay 合并图元。

组合验收固定同一内容与输入，比较四种配置：完整 IR／可见 IR 各自关闭及开启纹理。
覆盖“冷块生成 → 同块内滚动 → 跨块 → 回滚”，并加入内容／字体更新、DPI、
session、clip 变化与失败；逐项核对像素、块完整性、资产版本、hits／misses、
回退及整体成本。未变内容的同块滚动不能因可见片段变化持续重建；
新露出部分不得缺失。基于完整 IR 的旧热块结果不计为组合验收。
真实亚像素输入资格与回退分母按
[滚动方案](../architecture/long-text-scroll-resize-optimization-proposal.md#真实输入的缓存资格分母)报告，
保持实际滚动和交互坐标。
