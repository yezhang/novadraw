# ADR-059：可选分阶段文字引擎与宽度复用

类型：`architecture-decision`

能力归属：Core 阶段协议与资产账本，文字引擎分析/重排，Flow 接入。

状态：已接受，修订 2，2026-11-02。

## 问题

宽度变化通常不改变字体选择和 shaping；单一 layout 调用却重复分析全部文本。
若直接暴露默认引擎私有资产，外部引擎无法使用相同复用、失败与预算合同。

## 决策

所有引擎共用可选阶段能力；Core 捕获一次调用绑定，资产按实例身份与精确输入登记。
先查询有效资产，再判断新增准入；已有有效资产不被新增预算误拒绝。
计费账本随 registry 生命周期，返回值完整受检。阶段失败保留原始 source 与复合
失败。仅缺省能力、确定无法准入或通过返回检查的成功缺失允许完整回退；
预算、绑定、协议或扩展错误明确拒绝，不以回退掩盖失败，不发布不完整资产或布局。

## 替代与代价

不强制所有引擎支持阶段协议，不让 Core 解读默认引擎私有 payload，也不近似复用。
阶段协议增加身份、计费和等价验证成本；只有在完整结果等价及真实场景收益成立后
才接入。接受协议不表示默认引擎或 Flow 的所有切片已经完成。
