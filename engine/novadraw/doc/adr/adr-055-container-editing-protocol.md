# ADR-055：容器编辑与父坐标协议

类型：`architecture-decision`

能力归属：Editor 受检计划与父域坐标；应用原子模型命令。

状态：已接受，修订 2，2026-10-29。

## 问题

移动、创建与换父涉及不同父域；若工具直接写模型，或把 contents 坐标当成所有
容器坐标，预览、命令与历史会失去一致的资格和提交保证。

## 决策

Editor 生成受检容器计划，应用负责原子模型命令。
资格、父域映射、唯一批次锚点与身份恢复使用同一开放协议。
计划准备不修改模型，执行时重新检查版本与资格；外部策略与内置策略同模型。

## 替代与代价

不在 Editor 克隆业务模型或执行隐式多步写入，也不在工具中各自维护父域转换。
应用需实现原子命令，Editor 需保留计划输入与有效性检查；
跨外部模型的原子性不能由 Core/Viewer 代为承诺。
